## 三、关键差距根因分析

### 3.1 PSNR严重不达标 (-15.6 dB)

**问题**: 场景渲染PSNR 22.38 dB << 38 dB目标

**根因分析**:
1. **SH低阶限制** (仅2阶9个basis)
   - 无法表示高频光照细节
   - DC和线性分量误差直接影响亮度

2. **训练数据不足**
   - 仅125探针 × 7 light configs = 875样本
   - 任务书预期: 15K探针 × 24时刻 = 360K样本 (408×差距)

3. **模型容量不足**
   - K30_r8: 8,340参数
   - 可能需要更大rank或更多Gaussian

4. **物理约束缺失**
   - 无能量守恒约束 → 系统性亮度偏差
   - 仅时间平滑正则化不足

**改进路径** (按优先级):
- ✅ **P0 (立即)**: 增加rank到10-12，增加K到40-50
- ✅ **P0**: 扩展训练数据到更多探针和光源配置
- ✅ **P1**: 添加能量守恒约束损失
- ⚠️ **P2**: 考虑使用3阶SH (16 basis) 提升频率表达

---

### 3.2 时间一致性未验证

**问题**: tLPIPS指标完全未测试

**根因**:
- 当前数据集非时序 (随机5D参数组合)
- 无连续时间帧可用于计算tLPIPS

**改进路径**:
- ✅ **P0**: 生成时序数据集 (6am-6pm, 每小时1个)
- ✅ **P0**: 实现tLPIPS计算 (相邻帧LPIPS)
- ✅ **P1**: 验证时间平滑性 (相邻帧MAE)

---

### 3.3 实时解压优化缺失

**问题**: Temporal LRU Cache、预测性解压、融合CUDA全部未实现

**根因**:
- 当前处于Stage 2 (基础压缩验证阶段)
- 实时优化属于Stage 3+任务

**改进路径**:
- ✅ **P1**: 实现Temporal LRU Cache (预期降至<0.05ms平均)
- ✅ **P2**: 实现双线程预测性解压
- ⚠️ **P3**: CUDA kernel融合 (需要底层优化)

---

### 3.4 可编辑性功能缺失

**问题**: 光照解耦、天气编辑、局部编辑全部未实现

**根因**:
- 属于Stage 4 (高级功能)
- 当前优先级低于核心压缩和质量

**改进路径**:
- ⚠️ **P2**: 光照解耦 (直接光=l=1分量, 间接光=l=0+l=2)
- ⚠️ **P3**: 天气模板 (晴天/阴天/日落参数预设)
- ⚠️ **P3**: 局部编辑 (Mask + 微调优化)

     - 探针: 125→500 (4×)

     - 预期提升: +2-3 dB
   - **方法3**: 添加能量守恒约束
     - 损失: $\mathcal{L}_{energy} = ||\text{incoming} - \text{outgoing}||_1$
     - 权重: λ=0.01
     - 预期提升: +1-2 dB (系统性亮度偏差修正)

2. **验证时间一致性**
   - 生成24时刻时序数据集
   - 计算tLPIPS (目标<0.05)
   - 验证相邻帧平滑性

### 2. 添加能量守恒约束 (2天)
```python
def energy_conservation_loss(sh_coeffs, lambda_energy=0.01):
    # 简化版: DC分量 (l=0) 应近似为全方向辐射积分
    dc_component = sh_coeffs[:, :3]  # [B, 3] (RGB)
    # 约束: DC应为正值 (能量非负)
    energy_loss = torch.clamp(-dc_component, min=0).mean()
    return lambda_energy * energy_loss

# 预期: 修正系统性亮度偏差 → +1-2 dB
```
