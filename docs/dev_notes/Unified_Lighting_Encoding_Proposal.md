# 通用动态光照编码器升级方案 (Physics-Informed Ψ)

**目的**  
在保持现有 PG-GCPL 低秩+高斯框架的前提下，将光照参数编码从固定物理基函数升级为**物理约束的可学习映射**，实现“理论优雅性 + 工程通用性”的平衡，并为任意维度的可控光照参数提供统一入口。

---

## 1. 背景与动机

当前 PG-GCPL 形式:

```
SH(p, θ) = Σ_j G_j(p) × [ U_j @ (C_j @ Φ(θ)) ]
```

其中 Φ(θ) 是手工物理基函数（sin/cos/强度/色温/云量等）。

问题:
- 对 TOD 等低频远场光照非常有效，但对**人造光源、局部高频变化**表达力不足。
- 物理基函数对“通用动态光照”并不完备，强行限制会导致高 rank 或能量损失。

目标:
在不破坏现有结构的前提下，扩大参数映射的函数空间，同时保持可解释性与可控性。

---

## 2. 统一公式 (单一、完整、优雅)

将 Φ(θ) 升级为 Ψ(θ):

```
SH(p, θ) = Σ_j G_j(p) × [ U_j @ Ψ(θ) ]
```

其中 Ψ(θ) 是 **Physics-Informed Neural Mapping**，结构为:

```
Ψ(θ) = concat( Φ_phys(θ), Φ_learned(θ) )
```

- Φ_phys(θ): 可解释物理特征（sin/cos、log、exp 等）
- Φ_learned(θ): 小型 MLP / hash encoding / latent embedding

对外只暴露 Ψ(θ)，保持公式统一性；  
对内保留物理先验，增强泛化与可解释性。

---

## 3. 模块化设计

### 3.1 物理通道 Φ_phys
适用于已知物理参数（太阳角度、强度、色温、云量等）:

示例特征:
- sin(azimuth), cos(azimuth)
- sin(zenith), cos(zenith)
- log(intensity)
- color_temp (归一化)
- exp(-cloud)

### 3.2 学习通道 Φ_learned
适用于复杂或未知光照变化（人造光源、开关、移动、局部遮挡）:

候选实现:
- Small MLP (2-3 层, 32-64 hidden)
- Hash encoding (小尺寸)
- Latent embedding (Autodecoder)

---

## 4. 完备性与可解释性平衡

不再使用“主项 + 残差”的术语，而是**统一映射 Ψ**。
通过约束保持物理通道主导:

建议约束:
1. **能量占比约束**  
   限制 learned 通道贡献的 L2 能量比例:
   ```
   ||Φ_learned|| / (||Φ_phys|| + ||Φ_learned||) < α
   ```
2. **正交约束 (optional)**  
   鼓励 learned 通道与物理通道低相关。
3. **稀疏/小幅度约束**  
   对 learned 通道权重加 L1/L2 惩罚，避免过度依赖。

---

## 5. 训练与推理流程 (保持原结构)

训练:
1. 计算 Φ_phys(θ)
2. 通过 MLP 得到 Φ_learned(θ)
3. 拼接为 Ψ(θ)
4. 使用原有 PG-GCPL 的低秩与高斯混合结构训练

推理:
输入 (probe_pos, light_params) -> Ψ(θ) -> SH 输出  
接口不变，仅替换编码器实现。

---

## 6. 实验设计 (必须的消融)

建议最小实验矩阵:

| 方案 | 编码器 | 目标 |
|------|--------|------|
| A | Φ_phys only | 物理先验基线 |
| B | Φ_learned only | 纯数据驱动 |
| C | Ψ = [phys + learned] | 统一方案 |

关键指标:
1. SH MAE / RMSE
2. 场景渲染 PSNR / SSIM
3. 外推性能
4. Learned 通道能量占比

结论目标:
证明方案 C 在精度与泛化之间达到最佳折中，同时保持解释性。

---

## 7. 风险与控制

风险:
- MLP 学习通道过强，掩盖物理先验
- 过大 Ψ 维度会削弱低秩压缩优势

控制策略:
- 限制 learned 通道维度
- 引入能量/稀疏约束
- 在文档中明确“物理主导 + 学习补完”

---

## 8. 与“通用动态光照”的关系

本方案不是“任意动态场景”，而是**任意可参数化动态光照**:
- TOD 仍然适用 (phys 主导)
- 人造光源/开关/移动灯光可由 learned 通道吸收

这样既保持了理论清晰性，也保证工程落地。

---

## 9. 下一步落地建议

1. 将 Φ(θ) 实现替换为 Ψ(θ) 模块  
2. 统一 1D/5D 输入接口 (schema 驱动)  
3. 增加 learned 通道约束项  
4. 做最小消融实验 (A/B/C)
