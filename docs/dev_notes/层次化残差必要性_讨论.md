# 层次化残差必要性讨论（论文段落）

在本研究中，模型输出为二阶球谐（SH）系数，其本质是对场景全局低频光照的紧凑表示。因此，预测结果在视觉上呈现平滑、低频的光照分布，实验中 PSNR/SSIM 已达到较高水平，这意味着**在当前数据与表示阶数下，重建质量并非残差设计的瓶颈**。从这一角度看，层次化残差并非“提升画质”的必要条件。  
然而，层次化结构的引入仍具有工程价值：其核心目标不是追求更高的视觉细节，而是**服务于压缩率与解压效率**。通过 L0（全局基底）与 L1（局部残差）的分解，可以在远场或低变化区域仅解压 L0，在高变化区域才激活 L1，从而降低平均解压开销并为缓存策略提供更清晰的粒度划分。因此，残差层在本工作中应被视为**面向系统效率的结构性设计**，而非单纯的画质提升模块。  
若未来扩展至包含硬阴影、高光或焦散等高频效应的数据集，残差层将同时具备**质量补偿**与**效率分层**的双重作用；但在当前 SH 低频设定下，其价值主要体现在对层次化与实时解压目标的支撑。
