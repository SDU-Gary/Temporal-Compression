# 通用动态光照探索路线图（实验优先）

**目的**  
在保持“物理结构化 PG‑GCPL”的基础上，向“通用动态光照”升级，并避免陷入纯理论优化而忽略可验证实验的陷阱。本路线图强调**最小可验证实验**，优先解决“管线割裂”与“表达力不足”两大瓶颈。

---

## 0. 核心判断（优先级结论）

**优先级最高的两个方向**：
1. **光源集合输入（Set Input）**  
   统一 1D/5D，解决数据与模型接口割裂问题。
2. **动态基调制（Dynamic Basis / FiLM）**  
   以极小参数代价提升对近场高频变化的表达能力。

其它方向（如直接/间接光分解）属于**学术加分项**，但不是当前破局关键。

---

## 1. 方向拆解：哪些是“救命的突破口”？

### 方向 A：光源集合输入（最高优先级）
**目标**：用统一的 Light Descriptor 表示“任意数量光源”。  
**效果**：1D/5D 仅是特例（N=1），彻底消除脚本割裂。

最小实现：
- 输入：光源列表 `{(RGB, pos, dir, size, type, ...)}_i`  
- Encoding：每个光源过 MLP → sum/mean/attention pooling  
- 输出：统一的 Ψ(L)

实验目的：
1) 单一模型跑通 1D 与 5D  
2) 简单多光源（太阳 + 路灯）可控查询

---

### 方向 B：动态基调制（高优先级）
**目标**：让空间基 U_j 随参数轻量调制，提升高频遮挡表达。  
**最小实现**：FiLM 方式

```
U'_j = U_j ⊙ γ(θ) + β(θ)
```

实验目的：
1) 固定 U vs 动态 U 在“移动点光源”上的误差对比  
2) 在相同 rank 下显著降低 MAE

---

### 方向 C：直接光 / 间接光分解（中优先级）
**说明**：适合显著提升阴影质量，但对工程复杂度要求高。  
**建议**：作为中期目标，不作为当前破局点。

---

## 2. “实验优先”路线图（最小闭环）

### Step 1：统一 Schema（最小可行）
定义一个通用 `Light_Descriptor`（固定维度，16~32 维）：
- 前 3 维：RGB 强度  
- 位置/方向：XYZ + dir  
- 剩余维度：色温、尺寸、开关状态等

**实验目标**：  
让 1D / 5D 数据通过同一套加载、训练逻辑跑通。

---

### Step 2：动态基调制实验（最小 FiLM）
在现有模型上加极小 FiLM 调制层：
- Baseline：固定 U_j  
- Variant：U_j + FiLM(θ)

**指标**：
- SH MAE / RMSE  
- 渲染 SSIM / PSNR  
- 训练稳定性（收敛速度、震荡）

---

### Step 3：光源集合输入实验（N=2 起步）
构造小型数据集：
- 光源 1：太阳（远场）  
- 光源 2：路灯/点光源（近场）  
- 探针固定（少量）  
- 参数组合：太阳角度 × 路灯强度

**目标**：  
验证 Set Input 能否比固定 θ 更稳定地拟合多光源变化。

---

### Step 4：规模化与泛化验证
- 增加光源数量（N=3,4）  
- 加入移动光源轨迹  
- 对比纯物理编码 vs 物理+学习编码  
- 记录模型参数量与压缩比

---

## 3. 失败预警与判定标准

- **若 Step 1 无法统一输入** → 先停在 1D/5D，继续理论没意义。
- **若 Step 2 无法降低误差** → 动态基调制无效，需检查数据采样或 rank。
- **若 Step 3 多光源失败** → Set Input 方案需引入注意力或更强编码。

---

## 4. 结论（当前最值得投入的方向）

- **方向 A（光源集合输入）**：解决“管线割裂”与“通用性”  
- **方向 B（动态基调制）**：提升表达力上限且成本可控  

两者合并可形成“统一、可控、可扩展”的动态光照压缩框架。
