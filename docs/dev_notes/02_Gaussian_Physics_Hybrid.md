**日期**: 2025-12-12
**方法**: Gaussian-Physics Hybrid Compression

## 核心思想

结合两种压缩策略：
- **空间压缩**：高斯混合模型（K个3D高斯）
- **时间压缩**：物理引导的低秩基函数（cos/sin太阳高度角）

### 数学表达

```
F(p,t) = Σ_j F_j(t) * G_j(p)

其中:
- G_j(p): 高斯j在位置p的权重
- F_j(t) = U_j @ Φ(t)  # 每个高斯的时间表示
- Φ(t) = coeffs_j @ [cos(θ), sin(θ), 1]  # 物理基函数
- U_j: [27, rank] 高斯j的空间基
```

### 架构图

```
[查询位置p, 时间t]
       ↓
[找到最近的K个高斯] ← K-Means聚类（初始化）
       ↓
对每个高斯j:
   1. 计算高斯权重: G_j(p)
   2. 计算太阳高度角: θ(t)
   3. 物理基: [cos(θ), sin(θ), 1]
   4. 时间权重: Φ_j(t) = coeffs_j @ 基
   5. SH系数: SH_j = U_j @ Φ_j(t)
       ↓
加权求和: SH(p,t) = Σ G_j(p) * SH_j(t)
```

## 实验设置

### 数据集

- **Scene**: method_test_v1（多探针场景）
- **Probes**: 343个探针
- **Time moments**: 6个时刻 [6, 9, 12, 15, 18, 21小时]
- **SH coefficients**: 每个探针27个系数
- **Train/Test split**: 奇数小时训练（3个），偶数小时测试（3个）

### 模型配置

```python
# 高斯混合参数
num_gaussians = 20  # K=20个高斯
rank = 5            # 低秩秩数

# 参数量
- 高斯位置 μ: K*3 = 60
- 高斯尺度 log_scale: K*3 = 60
- 空间基 U: K*27*rank = 2700
- 时间系数 coeffs: K*rank*3 = 300
总计: 3120 参数
```

### 训练设置

- **Optimizer**: Adam (lr=1e-3)
- **Epochs**: 1000
- **Loss**: MSE
- **Initialization**: K-Means聚类 + SVD初始化U矩阵

## 实验结果

### 测试集性能对比

| 方法 | Test MAE | Test RMSE | 参数量 | 压缩比 |
|------|----------|-----------|--------|--------|
| Baseline (full storage) | - | - | 55,566 | 1.00x |
| **Spline** | **0.0397** | 0.0741 | 27,783 | 2.00x |
| PhysicsOnly (global) | 0.1739 | 0.3807 | 150 | 370.44x |
| **GaussianPhysics (ours)** | 0.1141 | 0.2079 | **3,120** | **17.81x** |

### 关键发现

1. **✓ 混合方法实现了17.8x压缩**
   - 显著优于Baseline（1x）和Spline（2x）
   - 参数量：3,120个（合理规模）

2. **△ 精度低于Spline**
   - MAE比Spline高2.87倍
   - 绝对误差：0.1141（可接受但不理想）

3. **✓ 显著优于PhysicsOnly全局模型**
   - MAE: 0.1141 vs 0.1739（34%提升）
   - 证明空间高斯混合有效

4. **△ 训练受限于数据量**
   - 只有3个训练时刻，SVD只能提取rank=3（而非rank=5）
   - "Warning: Only 3 components available, using rank=3"

## 精度分析

### 为什么精度不如Spline?

**主要原因**：

1. **训练数据有限**
   - 只有3个时刻训练数据
   - SVD被限制为rank=3（能量100%但实际只有3个有效维度）

2. **高斯数量不足**
   - K=20个高斯覆盖343个探针
   - 平均每个高斯覆盖17个探针
   - 空间分辨率损失

3. **训练不充分**
   - 只训练1000 epochs
   - 最终loss仍在下降（0.0426）

4. **模型容量限制**
   - 每个高斯的U矩阵只有rank=3有效维度
   - 时间建模能力受限

### 可改进方向

1. **增加训练时刻**
   - 使用更多训练数据（例如6个时刻→12个时刻）
   - 允许SVD提取更高的秩

2. **增加高斯数量**
   - K=20 → K=50 或 K=100
   - 提升空间覆盖密度

3. **更长训练**
   - 1000 epochs → 5000 epochs
   - 使用学习率调度

4. **数据增强**
   - 使用数据增强技术扩充训练集

## 压缩比分析

### 参数量对比

```python
# Baseline: 每个探针每个时刻存储27个SH系数
Baseline = N * T * 27 = 343 * 6 * 27 = 55,566

# Spline: 每个探针存储训练时刻的27个系数
Spline = N * T_train * 27 = 343 * 3 * 27 = 27,783

# PhysicsOnly: 全局单一U矩阵（忽略空间变化）
PhysicsOnly = 27*rank + rank*3 = 150

# GaussianPhysics: K个高斯，每个有自己的U和coeffs
GaussianPhysics = K*(3 + 3 + 27*rank + rank*3)
                = 20 * (6 + 27*5 + 5*3)
                = 20 * 156
                = 3,120
```

### 压缩比权衡

```
方法                压缩比    精度损失
----------------------------------------
Spline             2.0x      0% (基准)
PhysicsOnly        370x      +338% (不可接受)
GaussianPhysics    17.8x     +187% (可接受)
```

**结论**：混合方法在压缩比和精度之间取得了合理平衡。

## 与任务书方法对比

### 任务书方法（MLP-based）

```python
# 空间：高斯混合
# 时间：MLP神经网络
F_j(t) = MLP_temporal([F_j^base, sun_dir(t)])

参数量: K*(6 + latent_dim) + MLP参数
      ≈ K*6 + (latent_dim*64 + 64 + 64*27)  # 假设隐藏层64维
      ≈ 几千到几万个参数
```

### 我们的方法（Physics-based）

```python
# 空间：高斯混合
# 时间：物理基函数
F_j(t) = U_j @ (coeffs_j @ [cos(θ), sin(θ), 1])

参数量: K*(6 + 27*rank + rank*3)
      = 20 * 156 = 3,120
```

### 对比

| 维度 | 任务书方法 | 我们的方法 |
|------|-----------|-----------|
| 空间建模 | 高斯混合 | 高斯混合 |
| 时间建模 | MLP（黑盒） | 物理基（白盒） |
| 参数量 | ~1万+ | 3,120 |
| 可解释性 | 低 | 高 |
| 训练速度 | 慢 | 快 |

- **3,120个参数**覆盖343个探针×6个时刻
- 比独立存储压缩17.8倍

### 2. 可扩展性

- **空间**：增加高斯数量提升空间分辨率

- **T越大，时间压缩优势越明显**

### 3. 物理可解释性

- 太阳高度角θ直接编码光照变化
- cos/sin基函数捕捉周期性
- 每个高斯学习局部光照模式

### 4. 初始化稳定

- K-Means提供良好的空间分布
- SVD提供最优的低秩初始化
- 训练稳定，无NaN问题

## 局限性

### 1. 训练数据不足

当前实验只有3个训练时刻，限制了SVD的秩。

**影响**：
- SVD只能提取rank=3（而非rank=5）
- 时间建模能力受限
- 精度低于理论最优

**解决**：
- 使用更多时刻训练（6+）
- 允许SVD提取完整的rank=5

### 2. 高斯数量-精度权衡

K=20个高斯覆盖343个探针，空间分辨率有限。

**影响**：
- 每个高斯平均覆盖17个探针
- 局部光照细节丢失
- MAE较高（0.1141 vs Spline 0.0397）

**解决**：
- 增加K到50-100
- 使用自适应高斯密度

### 3. 单时段实验

当前只在6小时范围（6-21点）测试。

**影响**：
- 未验证跨昼夜的泛化能力
- 太阳高度角范围有限

**解决**：
- 扩展到24小时全天实验
- 测试夜间（太阳在地平线下）场景

### 4. 缺少方位角

当前只用太阳高度角θ，未使用方位角φ。

**影响**：
- 时间表示不完整
- 无法区分相同高度角但不同方位的情况

**解决**：
- 扩展基函数：[cos(θ), sin(θ), cos(φ), sin(φ), 1]
- 参数增加：rank*3 → rank*5
