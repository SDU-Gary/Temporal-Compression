## 方法概述

### 数学表达

```
SH(t) ≈ U @ Φ(t)

U: 空间基 [27, k]
Φ(t): 时间权重 [k, T]
     = coeffs @ [cos(θ(t)), sin(θ(t)), 1]
```

### 参数量

```
物理基: 27*k + k*3 = O(30k)
神经基: 27*k + (2*32 + 32 + 32*k) = O(60k) + 常数

Cornell (k=5): 150个参数 (物理基) vs 391个参数 (神经基)
House (k=4):   120个参数 (物理基) vs 332个参数 (神经基)
```

**结论**: 神经基参数量过大，**不推荐使用**。

## 核心洞察

### 1. Cornell Box：方法优于Baseline

```
Test MAE: 0.0207 (Ours) vs 0.0312 (Spline)
        → 33.5% 提升！
```

**为什么？**
- 物理基函数（cos/sin）捕捉了太阳路径的平滑性
- U矩阵通过SVD学习到了最优的空间基

### 2. House：接近Baseline

**但可接受**：
- 绝对误差极小（0.0002）
- 压缩比2.92x
- Trade-off合理

### 3. 为什么Cornell Box效果更好？

**假设**：
- House场景光照变化**极其平滑**（Spline MAE=0.0002）
- Cornell Box光照变化较复杂（Spline MAE=0.0312）
- **物理基在复杂场景更有优势**

物理基提供了"太阳路径"的先验，这在：
- 简单场景：不必要（Spline已经够好）
- 复杂场景：有帮助（正则化效果）

## 局限性

### 1. House场景精度下降24.3%

虽然绝对误差小，但相对误差增加。

**可能原因**：
- House光照太平滑，物理基的优势体现不出来
- 可能需要更高的秩(k)

### 2. 依赖太阳高度角

当前实现仅使用太阳高度角θ，未使用方位角φ。

**改进空间**：
- 加入方位角：Φ = coeffs @ [cos(θ), sin(θ), cos(φ), sin(φ), 1]
- 参数量增加到：27*k + k*5

### 3. 单探针验证

当前仅在单探针数据上验证。

**扩展方向**：
- 多探针共享U矩阵
- 空间压缩 + 时间压缩
