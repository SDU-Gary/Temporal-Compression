## 解决的核心问题

### 主要问题
1. **光照探针存储空间巨大**: 预计算全局光照(GI)技术中，光照探针数据随场景规模指数增长
2. **3D纹理内存消耗高**: 传统方法(VLM, APV)需要密集3D纹理进行实时插值，运行时内存占用大
3. **传统压缩方法不适用**: 光照探针不规则分布(仅在表面)，难以应用常规纹理压缩
4. **PCA方法压缩率低**: 基于主成分分析的方法在复杂场景中压缩率和质量权衡不佳

### 技术挑战
- 如何压缩不规则分布的高维信号(球谐系数)
- 如何在保持视觉质量的同时实现高压缩比(1:50)
- 如何实现快速实时解压缩(毫秒级)
- 如何减少运行时内存占用(从GB到KB级)

## 技术方法与Pipeline

### 核心创新1: 高斯探针压缩 (Gaussian Probe Compression, GPC)

#### 压缩框架
**问题抽象**:
- 探针数据: (x_i, y_i), x_i ∈ R³ (位置), y_i ∈ R^D (SH系数)
- 目标: 用参数更少的函数 f'(x) 近似 f(x): R³ → R^D
- 优化目标: min_{G,θ} L(G,θ) = 1/N Σ ||L(p_k) - L̂(p_k)||²

#### 高斯函数表示
采用3D Gaussian Splatting的定义:
```
G(x) = exp(-1/2 (x-μ)^T Σ^-1 (x-μ))
Σ = RSS^T R^T
```

**每个高斯 G_j 存储**:
- 位置 μ_j ∈ R³
- 缩放 s_j ∈ R³
- 旋转 q_j ∈ R⁴ (四元数)
- 潜在码 F_j ∈ R^D

#### 潜在特征计算
对于探针位置 p:
```
F(p) = (F⁰(p), F¹(p), ..., F^{n-1}(p))

F^i(p) = Σ_{j: p∈R(G_j)} F^i_j · G_j(p)

R(G_j) = {p | |p-μ_j| < 3·max(s⁰_j, s¹_j, s²_j)}
```
- R(G_j): 高斯影响范围(99%置信度包围球)
- 仅使用局部高斯(空间局部性)

#### MLP解码
```
L̂(p) = Φ([F(p), p]; θ)
```
- 网络: 2层隐藏层 × 64神经元
- 激活函数: Sigmoid
- 输入: 潜在特征(9维) + 位置(3维)
- 输出: SH系数向量(通常27维用于3阶SH)

### 高效实现

#### 前向传播 (Custom CUDA)
1. **空间分区**: 场景划分为均匀立方体
2. **高斯-立方体关联**:
   - 每个高斯计算影响半径
   - 记录与立方体的相交关系
   - GPU排序获取立方体→高斯映射
3. **并行推理**:
   - 每个探针查找所在立方体
   - 使用关联高斯计算潜在特征
   - 显著提升推理效率

#### 反向传播 (Manual Gradient Derivation)
不依赖PyTorch自动微分，手动推导梯度:
```
∂L/∂F^i_j = Σ_{p_k ∈ R(G_j)} (∂L/∂F^i(p_k)) · G_j(p_k)
```
同样推导 ∂L/∂μ_j, ∂L/∂s_j, ∂L/∂q_j

**优势**:
- 完全并行化
- 利用空间局部性减少计算
- 比PyTorch快数倍

#### 自适应低比特量化
收敛后进一步压缩:
```
ŝ^i_j = ⌊(s^i_j - s^i_min)/(s^i_max - s^i_min) · (2^b - 1)⌉

s̃^i_j = ŝ^i_j · (s^i_max - s^i_min)/(2^b - 1) + s^i_min
```

**量化流程**:
1. **粗调** (10%步数): 使用量化值，保留原始参数，Straight-through估计器
2. **精调** (10%步数): 冻结量化高斯，仅训练解码网络适应离散值
3. **存储**: 仅保存b位整数(通常b=10) + 网络权重(FP16)

### 核心创新2: 级联光照体积 (Cascaded Lighting Volume, CLV)

#### 问题背景
传统方法(VLM/APV)需要:
- 密集3D纹理填充光照信息
- 在开放区域和复杂区域均匀分布探针
- 导致数据冗余和内存消耗

#### CLV架构
**多级体积**:
- 4级级联: 块大小 2m, 4m, 8m, 32m
- 每级: 16³块
- 以视点为中心动态更新

**动态更新策略**:
1. **帧间对比**: 比较当前帧与上一帧视点位置/方向
2. **块查找**: 并行搜索需要更新的块对应的探针
3. **实时解压**:
   - 识别块内探针的影响高斯
   - 计算探针潜在特征
   - 网络推理重建SH系数
4. **块中心加权求和**: 计算块中心光照

**优化机制**:
- **帧分割**: 每帧最多更新64块，剩余排队下一帧
- **滚动索引**: 避免冗余块更新
- **LRU缓存**: 缓存计算结果利用时空局部性
- **八叉树**: 快速定位块内探针

#### 渲染流程
- 每像素根据距离选择对应级别体积
- 三线性插值采样3D纹理
- 近处用小纹理(细节)，远处用大纹理(粗略)

## Pipeline详解

### 完整压缩流程
```
输入: N个探针 {(x_i, y_i)}
  ↓
K-Means聚类初始化K个高斯
  ↓
梯度下降优化 (10,000步)
  - 前向: 高斯加权→MLP解码→SH系数
  - 反向: 自定义CUDA梯度传播
  - 优化器: Adan(高斯), Adam(解码器)
  ↓
自适应量化 + 粗调 (10%步数)
  - 量化为b位整数
  - Straight-through估计器
  ↓
冻结高斯 + 精调网络 (10%步数)
  ↓
输出: 量化高斯参数 + MLP权重
```

### 实时解压缩流程
```
运行时:
  八叉树存储探针位置
  LRU缓存存储块结果
  4级级联体积(16³块/级)
  ↓
每帧:
  对比视点变化
  ↓
  识别需更新块(最多64)
  ↓
  并行处理每个块:
    从八叉树查找块内探针
    ↓
    对每个探针:
      识别影响高斯→加权求和→MLP推理
    ↓
    加权计算块中心SH
  ↓
  更新3D纹理(GPU Compute Shader)
  ↓
  像素采样插值渲染
```

## 实现细节

### 训练参数
- **学习率**: 0.01
- **优化器**: Adan (高斯), Adam (解码器)
- **迭代次数**: 10,000 + 2,000量化
- **高斯比例**: 0.05 (5%探针数量，可调节质量)
- **潜在维度**: 9
- **量化位数**: 10-bit
- **Batch size**: 全部探针(~15,000)

### 网络架构
```
输入: [F(p): 9维, p: 3维] → 12维
  ↓
全连接 + Sigmoid → 64
  ↓
全连接 + Sigmoid → 64
  ↓
全连接 → 27维 (3阶SH × RGB)
```

### 初始化
- **高斯位置**: K-Means聚类中心
- **高斯尺度**: 基于簇中心最小距离
- **潜在码**: 随机初始化
- **网络权重**: 标准初始化

### CLV参数
- **级联层数**: 4
- **块尺寸**: [2m, 4m, 8m, 32m]
- **块数量**: 16³ / 级
- **每帧更新上限**: 64块
- **多线程**: 并行处理块更新

## 技术影响与局限

### 突破性贡献
1. **混合高斯-神经表示**:
   - 高斯编码空间相关性
   - MLP作为通用近似器
   - 优于纯PCA或纯神经方法
2. **极致压缩比**: 1:50，同时保持高视觉质量
3. **实时解压缩**: 毫秒级，支持60+ FPS渲染
4. **内存优化**: CLV避免密集探针布局，进一步节省内存
5. **自适应性**: 高斯分布自动适应探针分布

### 局限性

#### 1. **动态场景不支持**
- 预计算数据无法响应动态对象的光照变化
- 仅提供静态全局光照效果

#### 2. **训练速度较慢**
- ~1-2分钟 vs. PCA的秒级
- 大部分时间在PyTorch推理
- 改进方向: 完全CUDA实现(类似NTC)

#### 3. **简单场景不占优**
- 缺乏亮度和色度变化的场景中，PCA仍更快更简单

#### 4. **单时刻光照**
- 每个探针仅存储一个光照状态
- 未建模时变光照(Time of Day)

## 技术细节补充

### 球谐系数计算
探针数据为SH系数:
```
L^i = ∫ L_indirect(s) Y_i(s) ds, i = 1,2,...,n
```
- L_indirect: 采样的间接辐射度
- Y_i: 第i个SH基函数
- n: SH系数数量(3, 12, 27对应1,2,3阶)

### 高斯影响范围
```
R(G_j) = {p | |p-μ_j| < 3·max(s⁰_j, s¹_j, s²_j)}
```
- 包围球包含99%高斯分布
- 非最优(包含冗余立方体)但训练/推理时间可接受

### 拼接 vs. 归约
- 选择拼接L层特征: 允许独立并行处理
- 维度LF=9足够编码有用信息
- MLP远比编码贵时可考虑归约

### CLV滚动更新
```
每帧:
  1. 对比视点变化
  2. 识别新块(蓝色) + 废弃块(橙色)
  3. 新块和废弃块共享滚动坐标
  4. 仅更新新块，最小化纹理更新
  5. 最多64块/帧，剩余排队
```

### 存储格式
- **高斯参数**: FP16(位置3+尺度3+旋转4) + INT10×D(潜在码)
- **网络权重**: FP16
- **总大小**: 27.95KB (2%) ~ 160.87KB (20%)

## 技术范式转变

### 从PCA到高斯-神经混合
- **传统PCA**: 线性降维，全局/局部基
- **Gaussian Compression**: 非线性，空间自适应，神经解码

### 从密集纹理到稀疏探针+CLV
- **传统VLM/APV**: 密集3D纹理，均匀分布
- **CLV**: 稀疏探针，视点自适应，动态更新

### 从静态到时变(未来)
- **当前**: 单时刻静态光照
