## 解决的核心问题

### 主要问题
1. **光传输函数稀疏采样**: 传统光场只能提供稀疏的LT采样（~300个LED，~50-100个相机）
2. **重光照与视角合成分离**: 传统方法通常只能做其中一项，无法统一处理
3. **几何不完美**: 重建的几何和反照率存在误差，传统渲染会产生明显瑕疵
4. **简化假设限制**: 传统方法假设朗伯反射，无法处理高光、次表面散射等复杂效果

### 研究场景
- **光场采集**: One-Light-at-A-Time (OLAT) 图像（331个光源，64个相机）
- **几何输入**: 粗糙的几何代理（geometry proxy）+ UV纹理图集
- **目标**: 从稀疏观测插值6D光传输函数 f(x, ωi, ωo)

## 技术方法与Pipeline

### 核心思想: 半参数化神经光传输

**6D光传输函数**:
```
输入维度:
- UV位置 (2D): x
- 入射光方向 (2D): ωi
- 观察方向 (2D): ωo

输出: RGB辐射度 Lo(x, ωo)
```

### 双路径神经网络架构 (Section 3.3)

#### **观察路径 (Observation Paths)**
```
K个OLAT观测图像 (UV-space residuals)
  ↓
并行编码器 (共享权重)
  ↓
特征图 (多尺度)
  ↓
平均池化 (mean pooling)
  ↓
聚合特征 (对K个观测不变)
```

**输入**: K=1或3个邻近OLAT图像的残差图
**输出**: 多尺度聚合特征（传递给查询路径）

#### **查询路径 (Query Path)**
```
输入:
- 查询光源余弦图 (n·ωi)
- 查询视角余弦图 (n·ωo)
- 漫反射基底 (diffuse base)

U-Net编码器-解码器
  ↓ (拼接观察路径特征)
跨路径跳跃连接
  ↓
解码器
  ↓
残差图 ΔL
  +
漫反射基底 L̃o
  ↓
最终渲染 Lo = ΔL + L̃o
```

### 纹理空间输入 (Section 3.2)

#### **1. 余弦图 (Cosine Maps)**
```
光源余弦图: n(x) · ωi
视角余弦图: n(x) · ωo

特点:
- 通过射线投射计算可见性
- 提供粗略的投射阴影理解
- 对应渲染方程中的 (ωi·n) 项
```

#### **2. 漫反射基底 (Diffuse Base)**
```
构建方法:
1. 对每个视角求和所有OLAT图像
2. 在UV空间跨视角平均
3. 得到类似反照率的纹理图

物理意义: L̃o(x, ωi) = ρ(x) Li(x, ωi) (ωi·n(x))
```

#### **3. 残差图 (Residual Maps)**
```
残差 = OLAT图像 - 漫反射基底

捕获内容:
- 非漫反射效果（高光）
- 非局部效果（次表面散射）
- 全局光照（间接光）
```

### 残差学习方案 (Section 3.4)

**核心公式**:
```
Lo(x, ωo) = ΔL + L̃o(x, ωo)

其中:
- L̃o: 物理正确的漫反射渲染（包含硬阴影）
- ΔL: 网络预测的残差（学习高阶效果）
```

**优势**:
1. **物理先验注入**: 保证漫反射LT的物理正确性
2. **学习聚焦**: 网络专注学习高阶非漫反射效果
3. **隐式正则化**: 网络可"回退"到漫反射基底（输出零残差）

**能够建模的效果** (Figure 5, 6):
- ✓ **高光反射** (BRDFs): 正残差添加亮点
- ✓ **次表面散射** (BSSRDFs): 正残差表示额外照明
- ✓ **漫反射互反射** (Global Illumination): 正/负残差表示间接光

### 统一的重光照与视角合成 (Section 3.5)

**关键洞察**: UV纹理空间嵌入使得模型与任务无关

```
训练数据变化:
- 仅重光照: 固定视角，变化光源
- 仅视角合成: 固定光源，变化视角
- 同时进行: 交替变化光源和视角

模型架构: 完全相同！
```

**邻域采样策略** (Section 3.6):
- **重光照**: 从目标光源30°锥体内随机采样K=3个邻近光源
- **视角合成**: 从UV空间可见性重叠的邻近相机池采样
- **同时进行**: K=1，同时使用最近相机和光源

### 数据采集 (Section 3.1)

**硬件配置**:
- **RGB相机**: 64个，围绕被摄者
- **LED光源**: 331个方向光，OLAT扫描
- **IR系统**: 32个高分辨率IR相机 + 16个点照明投影仪（重建几何）

**数据规模**:
- **训练集**: 每场景 ~18,000帧（331光×55视角，过滤后~130 OLAT/相机）
- **保留测试**: 6个光照条件 + 2个视角
- **对齐**: 光流法对齐OLAT序列（~6秒扫描期间微小运动）

**分辨率**:
- UV空间: 1024×1024 (重光照/视角合成), 512×512 (同时进行)
- 相机空间: 1536×1128 (重光照/视角合成), 1024×752 (同时进行)

## 实验设置与结果

### 网络架构细节 (Section 3.6, Table 1-2)

**观察路径** (仅编码器):
```
O1: conv(16, 1×1, 1)   → H×W×16
O2: conv(16, 3×3, 2)   → H/2×W/2×16
...
O16: conv(2048, 3×3, 2) → H/256×W/256×2048
O17: conv(2048, 3×3, 1) → H/256×W/256×2048
```

**查询路径** (U-Net):
- 编码器: 从16通道逐级加倍至2048通道
- 解码器: 从2048通道逐级减半至3通道（RGB）
- 跨路径跳跃: 每个尺度拼接观察路径的mean(O_i)特征
- U-Net跳跃: 解码器拼接编码器同尺度特征

**激活函数**: Leaky ReLU (无normalization)

### 损失函数 (Section 3.6)

#### **鲁棒光度损失** (Barron 2019)
```
L_I = Σ_i √(CDF(YUV(Lo(xi, ωo) - L*o(xi, ωo)))²/c² + 1) - 1

其中:
- CDF: CDF9/7 小波分解
- YUV: 色彩空间转换
- c = 0.01: 尺度超参数
- 伪Huber损失 (α=1)
```

**优势**: 同时捕获高频和低频细节

#### **感知损失** (LPIPS, Zhang+ 2018)
```
L_P = VGG特征空间的ℓ2距离
```

**总损失**: L = L_I + L_P (等权重)

### 训练细节
- **优化器**: Adam (lr=2.5×10⁻⁴, β1=0.9, β2=0.999, ε=10⁻⁷)
- **Batch size**: 1
- **硬件**: NVIDIA Tesla P100
- **时间**: <12小时（真实场景）

**实验设置**: 从100k顶点逐步降采样至500顶点

**LPIPS对比** (500顶点极端情况):
- Floating Textures [2008]: ~0.070（存在缺失像素和高频错误）

**关键发现**:
1. NLT学会"幻觉化"未见区域（无缺失像素）

**实验**: 仅用60%光源训练（~75个光源/相机）

**现象**: 出现重影阴影（类似重心插值）

**结论**: NLT需要较密集光源以避免重影

**方法**:
1. 合成331个方向的OLAT图像
2. 每个光源用高斯近似
3. 按HDRI环境贴图线性组合

**效果**:
- ✓ 真实的高光和阴影
- ✓ 视角相关效果
- ✓ 可用于虚拟场景合成

### 同时重光照与视角合成 (Figure 10)

**结果展示**:
- **光照变化** (横轴): 不同光源方向
- **视角变化** (纵轴): 不同相机位置
- **质量**: 准确的阴影、全局光照、高光细节

**与NeRF对比** (Figure 11):

**视角合成**:
- NeRF: 模糊的面部高光、缺失眼睛高光、低频头发细节

**同时任务**:
- NeRF + Light: 无法合成硬阴影、模糊高光
- **NLT**: 准确硬阴影、清晰高光

**关键差异**: 几何代理在稀疏视角+光照变化时至关重要

### 消融实验 (Table 3-4, Figure 14)

#### **1. 无观察路径**
- PSNR: 32.56 (重光照), 34.43 (视角合成)
- **问题**: 过度平滑，缺失细节
- **原因**: 网络无法从邻近观测获取信息

#### **2. 无残差学习**
- PSNR: 33.65 (重光照), 34.49 (视角合成)
- **问题**: 难以学习硬阴影
- **原因**: 网络浪费容量学习反照率和基础阴影

**对比Deep Shading** (仅将diffuse base作为输入，无跳跃连接):
- Deep Shading LPIPS: 0.106 (重光照), 0.058 (视角合成)
- NLT w/o obs. LPIPS: 0.064, 0.037
- **结论**: 跳跃连接至关重要

#### **3. 无感知损失**
- PSNR: 34.43 (稍高)
- LPIPS: 0.066 (显著变差)
- **问题**: 阴影边界模糊、高频细节丢失

学习内容分类:

## 局限性

### 1. 场景特定训练
- 每个场景需单独训练 (<12小时)
- 无法泛化到新场景
- 需要大量OLAT数据 (~18k帧)

### 2. 静态场景假设
- 固定姿态和几何
- 动态场景需要固定UV参数化（未来工作）

### 3. 分辨率限制
- UV空间: 1024×1024固定
- 极近距离或小区域分配过少纹素
- **失败案例** (Figure 15): 闪光链等复杂高频效果

### 4. 光源密度要求
- 60%光源时出现重影阴影
- 需要较密集的OLAT采集

### 5. 无抗锯齿
- 中心采样，无内置AA
- 需要后处理或多样本

## 技术细节补充

### 渲染方程对比

**简化朗伯模型**:
```
L̃o(x, ωo) = ρ(x) Li(x, ωi) (ωi·n(x))

局限:
- 单一方向光（不是半球积分）
- 无BRDF（仅标量反照率）
- 无自发光Le
- 无散射/透射
```

**完整渲染方程**:
```
Lo(x, ωo) = Le(x, ωo) + ∫_Ω fs(x, ωi, ωo) Li(x, ωi) (ωi·n(x)) dωi

NLT目标: 学习 Lo - L̃o 的残差
```

### 网络参数量

**观察路径**: ~30M参数（编码器）
**查询路径**: ~35M参数（U-Net）
**总计**: ~65M参数 → ~260MB（float32）

**存储**: 2MB（模型压缩后）

## 总结

Neural Light Transport是**神经渲染领域的里程碑工作**，首次实现了高质量的同时重光照与视角合成。其半参数化设计、UV空间嵌入、双路径架构、残差学习方案为后续工作提供了完整的方法论框架。

对于"多时刻光照神经压缩"研究，NLT的核心思想（物理基底+神经残差、纹理空间表示、观察聚合）可直接扩展到时间维度，是不可或缺的技术基础。
