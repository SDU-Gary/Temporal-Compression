# Real-time Neural Rendering of Dynamic Light Fields

## 基本信息
- **作者**: Arno Coomans, Edoardo A. Dominici, Christian Döring, Joerg H. Mueller, Jozef Hladky, Markus Steinberger
- **机构**: Huawei Technologies (Switzerland, Germany, Austria), Graz University of Technology
- **发表**: EUROGRAPHICS 2024, Volume 43, Number 2
- **类型**: 动态光场神经渲染 + 实时缓存

## 解决的核心问题

### 主要问题
1. **实时高质量全局光照**: 路径追踪对于非平凡场景仍远达不到实时
2. **动态场景光传输缓存**: 现有神经渲染方法主要限于静态场景
3. **推理性能瓶颈**: 现有方法推理速度低或无法与现有渲染范式集成
4. **时空信号复杂性**: 如何高效捕获不同类型的时空动态（旋转、平移、光照变化）

### 研究场景
- **动态光场**: L(x, ω, t) - 空间、方向、时间的6D函数
- **已知几何**: 场景几何已知（与NeRF不同）
- **预计算**: 作为离线训练的辐射度缓存
- **实时查询**: 推理时仅需主光线相交 + 网络查询

## 技术方法与Pipeline

### 核心思想: 显式时空缓存

**目标函数**:
```
学习神经动态光场: Lθ(x, ω, t)
逼近真实光场: L(x, ω, t)

通过最小化渲染方程残差:
rθ(x, ωo) = Lθ(x, ωo) - E(x, ωo) - ∫Ω f(x, ωi, ωo) Lθ(x', -ωi) dωi⊥
```

### 网络架构 (Section 3.1)

**Tiny Fully-Fused MLP**:
```
输入: [基础参数, 多个编码]
  ↓
4个隐藏层 × 128神经元 (ReLU)
  ↓
输出: RGB辐射度

基础参数:
- x (3D): 位置
- n (3D): 法线
- ω (3D): 出射方向
- α (3D): 漫反射率
- t (1D): 时间
- uv (2D): UV坐标
```

**参数量**: ~65M → 存储 ~260MB (float32) → 压缩至 40-80MB

### 关键创新: 多编码组合 (Section 3.2)

#### **1. 4D时空编码 H(x,t)**
```
作用: 捕获空间-时间相关性
适用场景: 阴影移动、光线在空间中流动
优势: 追踪时空相干的光传输

例子 (Figure 4 - Rover):
- 快速旋转物体投射的阴影
- 地面上的动态阴影边界
```

#### **2. 3D空间编码 H(x)**
```
作用: 提取场景静态特征
适用场景: 几何固定的场景
优势: 稳定重建、提供基础空间信息
```

#### **3. 新颖的2D UV空间编码 H(uv)** ⭐
```
灵感来源: Object-space lighting [MNV+21]

作用: 改善快速移动物体的鲁棒性
原理: 在表面UV参数空间建立哈希网格

优势:
✓ 平移/旋转不变性
✓ 时空稳定的着色
✓ 避免3D空间中的高频动态效应

实现 (Appendix B):
1. Blender自动UV展开 (Smart UV Project, 66°角度限制)
2. 按表面积比例打包到UV atlas
3. 16级多分辨率哈希网格覆盖UV域
```

**UV编码效果** (Figure 5):
- 可视化: UV空间的辐射度预测
- 学习内容: 纹理空间着色
- 表面法线方向的辐射度

#### **4. 1D时间编码 H(t)**
```
作用: 高维时间表示 → 平滑光强变化
优势: 避免直接使用单个float t的不稳定性

对比 (Figure 3 - Cornell Box):
- MLP(H(x), t): 无法学习平滑过渡 ❌
- MLP(H(x), H(t)): 平滑低频光照变化 ✓
```

### 多分辨率哈希网格参数 (Appendix A)

**通用参数**:
```
基础分辨率: Nmin = 16
层数: L = 16
哈希表大小: T = 2^19 (≈524k条目)
分辨率增长:
  - 高分辨率模型: ×2 每层
  - 低分辨率模型: ×4 每层
```

**特征维度** (Table 5):
```
组合方式                    | 每层特征维度
----------------------------|------------------
H(x), t                     | F_H(x) = 8
H(x), H(t)                  | F_H(t) = F_H(x) = 8
H(t), H(x,t)                | F_H(t) = 2, F_H(x,t) = 8
H(x), H(t), H(x,t)          | F_H(x) = F_H(t) = 2, F_H(x,t) = 4
H(t), H(x), H(x,t), H(uv)   | 所有编码 = 2
```

### 编码组合策略

**场景类型 1: 快速移动物体** (Figure 4 - Rover)
```
问题:
- 旋转物体 → 高频阴影移动
- 物体不同部位切向速度不同 → 复杂时空频率

编码进化:
H(x), H(t)              → 无法捕获高频细节 (108.7 MB)
  ↓
+ H(x,t)                → 改善动态阴影 (87.8 MB)
  ↓
+ H(uv)                 → 重建精细细节 (78.8 MB) ✓

关键: UV编码解决旋转下的照明偏移学习困难
```

**场景类型 2: 静态几何+高频光照** (Figure 6 - Dining)
```
问题:
- 方向光旋转 + 桌子平移 → 非线性变换
- 墙上移动的硬阴影 → 高频边界

编码进化:
H(x), H(t)              → 跟不上灯光移动，丢失硬阴影
  ↓
H(t), H(x,t)            → 模糊的阴影边界 (121.8 MB)
  ↓
H(x), H(t), H(x,t)      → 准确捕获锐利边界 (87.8 MB) ✓
  ↓
+ H(uv)                 → 进一步降低误差 (78.8 MB)

关键: H(x) + H(x,t) 结合静态和动态优势
```

### 训练策略改进 (Section 3.3)

#### **1. 停止梯度 (Stop Gradient)** ⭐
```
原始残差:
rθ(x, ωo) = Lθ(x, ωo) - E(x, ωo) - ∫ f(...) Lθ(x', -ωi) dωi

修改为 (Equation 3):
rθ(x, ωo) = Lθ(x, ωo) - E(x, ωo) - ∫ f(...) sg(Lθ(x', -ωi)) dωi
                                                    ↑
                                            停止梯度流

原因:
- 网络出现2次: 1次出射辐射度 + N次入射辐射度
- 梯度只回传到出射辐射度 → 减小计算图
```

**效果** (Figure 7-8):
- Living Room: 停止梯度 → 场景更亮、颜色溢出正确
- 收敛速度: 10^-3 → 10^-2 RMSE (40k iterations)
- 训练速度: 计算图更小 → 更快迭代

**理论联系**: 类似深度强化学习的目标网络 [MKS+15, SB18]

#### **2. 改进采样策略**

**面积重要性采样**:
```
构建CDF: 按物体表面积分配采样概率

vs. 均匀对象采样:
- 均匀: 茶杯与整个墙采样数相同 ❌
- 面积: 大表面获得更多样本 ✓
```

**效果** (Figure 9):
- Dining Room: 面积采样显著改善收敛
- RMSE: 10^-1 → 10^-2 (更快且更低)

**采样分布可视化** (Appendix C, Figure 16):
- Bedroom场景: 均匀 vs. 面积采样热图
- 面积采样 → 梯度对真实辐射度分布的偏差更小

#### **3. 时序稳定性: 指数移动平均 (EMA)**
```
问题: 高频哈希网格 → 相邻帧高频模式闪烁

解决方案:
EMA(H(t), H(x,t), t) → 喂给网络前平滑

注意:
- 仅对时间子集应用EMA
- 全输入EMA在静态场景好，但动态几何/相机会产生重影
```

**效果** (Figure 10):
- with EMA: 时序平滑
- without EMA: 闪烁伪影

### 自训练方法 (Self-Training)

**蒙特卡洛估计残差范数** (Equation 2):
```
L(θ) ≈ (1/N) Σ rθ(xj, ωo,j)² / p(xj, ωo,j)

N = 2^14 个样本 (位置 + 方向对)
M = 32 个半球样本/对 (BSDF + 光源多重重要性采样)
```

**动态场景扩展**:
```
时间采样策略:
- 每batch: 单个时间步 t
- 跨batch: 随机采样 t
- 结果: 单batch有偏，极限下无偏 [GBC16]

未采用: 同batch内混合多个t (内存成本过高)
```

### 编码组合消融 (Section 3.2总结)

**关键发现**:
1. **H(x,t) vs. H(x)+H(t)**: 时空编码捕获移动阴影
2. **H(x)+H(x,t)**: 结合静态和动态优势 → 锐利边界
3. **+ H(uv)**: 快速移动物体的旋转不变性 → 精细细节

**内存-质量权衡**:
- 更多编码 → 更低单编码维度 → 总参数量持平
- 性能递进提升（Figure 4, 6可视化）

### 哈希网格 vs. 稀疏特征网格 (Figure 12)

**对比**: Instant NGP哈希 vs. Neural Radiosity稀疏网格

**结果**:
- 质量相当或更好
- 无需预计算（稀疏网格需1小时/场景）
- 更模块化、易扩展到其他域（时间、UV）

## 技术突破与贡献

### 1. 实时动态光场范式

**首次实现**:
- ✓ 60+ FPS @ 1920×1080 动态光场渲染
- ✓ 20× 加速比（vs. Neural Radiosity, Active Exploration）
- ✓ 紧凑内存（40-80 MB）
- ✓ 与蒙特卡洛光线追踪无缝集成

**应用场景**:
- 自由视点视频 (Free-viewpoint video)
- 交互式多视角渲染
- 流式渲染 (Streaming rendering)
- 混合渲染 (动态背景 + 传统前景)

### 2. 新颖的UV空间编码

**创新性**:
- 首次将多分辨率哈希网格应用于UV域
- 捕获表面空间的光照相干性
- 平移/旋转不变性 → 简化学习任务

**优势**:
```
3D空间编码 H(x,t):
- 旋转物体 → 网格单元状态剧烈波动
- 不同切向速度 → 复杂时空频率

UV空间编码 H(uv):
- 表面着色相对稳定
- 与全局变换解耦
- 时空一致的表示
```

### 3. 多编码组合策略

**方法论贡献**:
- 不同维度编码捕获不同动态类型
- 等参数量下递进提升质量
- 通用框架适应多种场景

**编码职责分工**:
```
H(x)   : 静态场景特征
H(t)   : 平滑时间变化
H(x,t) : 时空相干的光传输（移动阴影）
H(uv)  : 表面空间光照（旋转不变）
```

### 4. 训练策略改进

**停止梯度**:
- 理论: 类似强化学习目标网络
- 实践: 数量级质量提升 + 更快训练

**面积重要性采样**:
- 按表面积分配样本 → 更平衡的梯度
- 对表面积差异大的场景显著改善

**时序稳定性**:
- EMA平滑时间输入 → 减少闪烁
- 仅对时间子集应用 → 避免动态几何重影

### 5. 性能优化技术

**小网络 + 强编码**:
```
4层 × 128神经元 (vs. 大网络)
  ↓
推理速度: ~13ms (1920×1080)
  ↓
多编码补偿网络容量
```

**Fully-Fused实现**:
- tiny-cuda-nn [Mül21] 优化推理
- 16-bit量化权重

**内存-性能权衡**:
- 降低哈希网格中间层 → 50%内存，35%更快
- 质量略降但可接受

## 局限性

### 1. 合理UV映射依赖
- 需要无重叠、有界的UV映射
- 当前: Blender自动展开（可能有重叠）
- 未来: 更高效的UV生成与打包 [LVS18]

### 2. 小网络容量限制
- 高频伪影（训练早期）
- 方向相关效果（光泽材质）困难
- 未来: 编码方向向量或更大网络

### 3. 合成场景限制
- 仅支持表面采样
- 不支持体积元素（雾、参与介质）
- 潜在扩展: 体积边界采样或内部多采样

### 4. 一维动态参数
- 当前: 单参数 t 控制所有动态
- 扩展: 多维参数空间（材质变化、多对象动画）
- 未来: 更高维输入域

### 5. 新对象泛化
- 训练时未见的对象 → 错误着色
- 潜在方案: 单独着色pass采样动态光场

### 6. 无抗锯齿
- 中心采样，无内置AA
- 需要后处理或多样本

## 与研究主题的关联

**"面向多时刻光照的层次化神经压缩方法"相关性分析:**

✓ **高度相关点:**
1. **时空动态建模**:
   - 本文: t维度 + 多编码 → 复杂动态
   - 研究: 多时刻光照 → 时序光照变化

2. **神经压缩**:
   - 40-80 MB紧凑表示完整动态光场
   - 哈希网格 + 小网络 = 高效压缩

3. **层次化思想**:
   - 多维度编码分工 (H(x), H(t), H(x,t), H(uv))
   - 不同编码捕获不同频率/类型动态

4. **实时推理需求**:
   - ~13ms推理 → 可用于交互式应用
   - 与传统渲染管线无缝集成

✓ **可借鉴技术:**
1. **UV空间编码**:
   - 表面参数空间建模 → 时空一致性

## 技术细节补充

### 自训练损失细节

**Huber损失** (δ=1.0):
```
L_huber(a) = {
  0.5 * a²           if |a| ≤ δ
  δ * (|a| - 0.5δ)   otherwise
}

优势: 对异常值鲁棒
```

**采样参数**:
```
N = 2^14 = 16,384  : 位置-方向对
M = 32             : 每对的半球样本
总样本/batch = 524,288 辐射度估计
```

### 实现细节

**框架集成**:
```
Mitsuba 3 [JSR+22]: 路径追踪 + 场景管理
  ↓
PyTorch [PGM+19]: 网络训练
  ↓
tiny-cuda-nn [Mül21]: 快速推理

动态场景处理: 视为静态场景序列（Mitsuba限制）
```

**训练技巧**:
- 样本缓存: 重用样本跨迭代 → 均摊采样成本
- 批处理时间: 每batch单时间步 → 避免内存爆炸

**推理优化**:
- 仅第一（非反射）次bounce查询缓存
- 反射表面: 追踪反射光线
- 避免学习镜面的复杂场景反射

### 场景动态类型分析

**平移不变性**: H(uv) 完美捕获
**旋转不变性**: H(uv) 大幅改善（Figure 4）
**非线性变换**: H(x,t) + H(x) 组合处理（Figure 6）
**光源变化**: H(t) 平滑 + H(x,t) 追踪
**复杂碰撞**: Bunnies场景成功（Table 3）

### 视觉质量分析

**高频伪影来源**:
1. 哈希碰撞
2. 训练不充分
3. 网络容量不足（方向相关）

**缓解方法**:
- EMA时间输入 (Figure 10)
- 抖动哈希网格采样（未来工作）
- 后处理滤波

**vs. Active Exploration质量差异**:
- Active Exploration: 低频模糊（网络过大？）
- **Ours**: 高频噪声（哈希网格？）
- 两者均可通过更长训练改善
