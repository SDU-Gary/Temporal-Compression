# NeRFactor: Neural Factorization of Shape and Reflectance Under an Unknown Illumination

## 基本信息
- **作者**: Xiuming Zhang, Pratul P. Srinivasan, Boyang Deng, Paul Debevec, William T. Freeman, Jonathan T. Barron
- **机构**: MIT CSAIL & Google Research (USA)
- **发表**: ACM SIGGRAPH 2021 (ACM Transactions on Graphics, Vol. 40, No. 6, December 2021)
- **项目**: https://people.csail.mit.edu/xiuming/projects/nerfactor/
- **代码**: 开源

## 解决的核心问题

### 主要问题
1. **逆渲染的病态性**: 从单一未知光照下的图像恢复形状和反射率是严重欠约束问题
2. **形状-反射率-光照歧义**: 三者相互耦合，难以分离
3. **阴影与反照率混淆**: 传统方法将阴影误认为反照率变化
4. **NeRF几何噪声**: NeRF体积密度生成的法线和可见性过于嘈杂，无法直接用于重光照

### 问题设定
- **输入**: 多视角图像 + 相机位姿 (单一未知光照条件)
- **输出**: 3D神经场 (法线、可见性、反照率、BRDF) + 环境光照
- **假设**: 硬表面、单次直接光照、非金属材质

## 技术方法与Pipeline

### 整体Pipeline

```
阶段1: NeRF预训练
多视角图像 → NeRF σ-体积 (冻结)

阶段2: 几何蒸馏预训练
NeRF σ-体积 → 法线MLP初始化
            → 可见性MLP初始化

阶段3: 联合优化
法线MLP + 可见性MLP (微调)
反照率MLP (从头训练)
BRDF身份MLP (从头训练)
光照探针像素 (直接优化)
```

### 核心组件详解

#### 1. 形状表示 (Shape)

**表面点 (Surface Points)**
```
x_surf = o + ∫₀^∞ T(t)σ(r(t)) t dt · d

其中:
- r(t) = o + td: 相机射线
- T(t) = exp(-∫₀^t σ(r(s))ds): 累积透射率
- σ: NeRF体积密度
```

**表面法线 (Surface Normals)**
- **解析法线**: n_a(x) = -∇σ(x) / ||∇σ(x)||
- **MLP重参数化**: f_n: x_surf ↦ n
- **损失函数**:
```
ℓ_n = Σ_x [λ₁/3 ||f_n(x) - n_a(x)||₂² +
           λ₂/3 ||f_n(x) - f_n(x+ε)||₁]
```
  - λ₁=0.1 (接近NeRF法线)
  - λ₂=0.05 (空间平滑)
  - ε ~ N(0, 0.01²): 随机扰动

**光照可见性 (Light Visibility)**
- **解析可见性**: v_a(x, ω_i) - 从NeRF σ体积光线行进
- **MLP参数化**: f_v: (x_surf, ω_i) ↦ v
- **损失函数**:
```
ℓ_v = Σ_x Σ_ω_i [λ₃|f_v(x,ω_i) - v_a(x,ω_i)|² +
                  λ₄|f_v(x,ω_i) - f_v(x+ε,ω_i)|]
```
  - λ₃=0.1, λ₄=0.05
  - 512个固定光照位置 (16×32探针)
  - 仅对空间平滑，不对光照方向平滑

#### 2. 反射率模型 (Reflectance)

**完整BRDF模型**
```
R(x, ω_i, ω_o) = a(x)/π + f_r(x, ω_i, ω_o)
                  ↑漫反射    ↑镜面反射
```

**反照率 (Albedo)**
- **MLP**: f_a: x_surf ↦ a ∈ [0.03, 0.8]³
- **平滑损失**:
```
ℓ_a = λ₅ Σ_x (1/3)||f_a(x) - f_a(x+ε)||₁
```
  - λ₅=0.05

**学习的BRDF先验**
- **数据集**: MERL 100种真实材质测量
- **参数化**: Rusinkiewicz坐标 (φ_d, θ_h, θ_d) - 3自由度 (各向同性)
- **潜在空间学习** (GLO方法):
```
f'_r: (z_BRDF, (φ_d, θ_h, θ_d)) ↦ r (achromatic)

坐标转换: g: (n, ω_i, ω_o) ↦ (φ_d, θ_h, θ_d)
```
- **训练**: 优化MLP权重 + 100个3维潜在码 z_BRDF
- **应用**: 冻结f'_r，仅预测空间变化的z_BRDF
- **身份MLP**: f_z: x_surf ↦ z_BRDF
- **平滑损失**:
```
ℓ_z = λ₆ Σ_x ||f_z(x) - f_z(x+ε)||₁ / dim(z_BRDF)
```
  - λ₆=0.01

**最终BRDF**
```
R(x, ω_i, ω_o) = f_a(x)/π + f'_r(f_z(x), g(f_n(x), ω_i, ω_o))
```

#### 3. 光照 (Lighting)

**表示**: HDR纬度-经度图 (16×32分辨率)
- 直接优化512个像素值 (无参数化网络)
- 支持高频光照 → 硬阴影

**梯度惩罚** (平滑先验):
```
ℓ_i = λ₇ (||[-1 1] * L||₂² + ||[-1; 1] * L||₂²)
```
- λ₇=5×10⁻⁶
- *: 卷积操作

### 渲染方程

**直接光照渲染**
```
L_o(x, ω_o) = Σ_ω_i R(x, ω_i, ω_o) L_i(x, ω_i) (ω_i · n(x)) Δω_i

其中:
- L_i(x, ω_i) = f_v(x, ω_i) · 光照探针(ω_i)
- Δω_i: 光照采样立体角
```

**完整损失**
```
L_total = ℓ_recon + ℓ_n + ℓ_v + ℓ_a + ℓ_z + ℓ_i
```
- ℓ_recon: 重建损失 (MSE, 权重=1)

### 实现细节

**网络架构**
- NeRF: 默认架构 (Mildenhall et al. 2020)
- 其他MLP: 4层×128隐藏单元 + 跳跃连接
- 位置编码:
  - 3D位置: 10层
  - 方向: 4层

**训练策略**
- 优化器: Adam (默认超参数)
- NeRF: 2000轮 (6-8小时, 4×TITAN RTX)
- 几何预训练: 200轮 (20分钟)
- 联合优化: 100轮 (30分钟)

## 关键创新点

### 1. NeRF几何蒸馏
**问题**: NeRF几何包含高频噪声，视图合成中不可见但在重光照中产生伪影

**解决方案**:
- 提取期望表面点 (Eq. 1)
- MLP重参数化法线和可见性
- 平滑正则化 + NeRF伪监督

**效果**: 图3显示法线角度误差从32°降至22°

### 2. 数据驱动BRDF先验

**vs. 解析BRDF** (microfacet模型):
- 解析模型: 所有参数组合等概率 → 缺乏先验
- 学习模型: 从100种真实材质学习合理分布

**GLO训练**:
```
最小化: log(HDR反射率)的MSE
优化: MLP权重 + 100个z_BRDF初始化
```

**优势**: 表1显示学习BRDF略优于microfacet (PSNR 28.71 vs 29.16)

### 3. 显式可见性建模

**重要性**:
- 分离阴影与反照率 (图4)
- 合成任意光照下的软/硬阴影 (图5)

**vs. 不建模可见性**:
- NeRD (Boss et al. 2021): 阴影残留在反照率
- PhySG (Zhang et al. 2021b): 无阴影合成能力

### 4. 几何预训练的必要性

**实验** (表1 "w/o geom. pretrain."):
- 不预训练: 反照率MLP错误地将阴影解释为"绘制"的反照率变化
- 法线角度误差: 22.13° → 25.53°
- 反照率PSNR: 28.71 → 27.79

**原因**: 可见性需要合理初始化，否则优化陷入局部最优

## 技术局限

### 1. 光照分辨率限制
- **16×32分辨率**: 无法恢复更高频内容
- **影响**: 非常硬阴影或镜面高光有残留 (图S1 Case D)
- **原因**: BRDF低通滤波 + 512可见性MLP查询开销

### 2. 仅建模直接光照
- **假设**: 单次弹射
- **缺失**: 间接光照、全局光照
- **表现**: 图5 (D) 背光场景比GT暗

### 3. 依赖NeRF初始化质量
- **问题**: NeRF错误几何 (如远处漂浮几何) → 错误阴影
- **观察**: vasedeck, pinecone有远处错误几何投影阴影
- **缓解**: 3D包围盒限制 (但治标不治本)

### 4. 材质限制
- **不支持**: 金属 (色彩镜面)、各向异性、透明、半透明
- **原因**:
  - MERL数据集仅100种非金属材质
  - 假设白色镜面高光
  - 体积光传输未建模

### 5. 低频光照恢复
- **过度平滑**: 图4光照探针 (梯度惩罚 + BRDF低通)
- **下半球错误**: 仅观察上半球 → 下半球光照不可靠
- **不影响重光照**: 因为重光照用新探针

## 并发工作对比

### NeRV [Srinivasan et al. 2021 CVPR]
- **输入**: 多个已知光照条件
- **可见性**: 显式建模 (类似NeRFactor)
- **BRDF**: 解析microfacet
- **优势**: 多光照更强约束
- **劣势**: 需要多次拍摄

### NeRD [Boss et al. 2021 ICCV]
- **输入**: 单一未知光照 (同NeRFactor)
- **可见性**: 不建模 → 阴影残留
- **BRDF**: 解析microfacet → 无先验
- **表现**: 表1显示NeRFactor整体更优

### PhySG [Zhang et al. 2021b CVPR]
- **BRDF**: 球面高斯 + microfacet
- **可见性**: 不建模
- **反射率**: 非空间变化 → 限制性强

### Neural Reflectance Fields [Bi et al. 2020]
- **输入**: 多个已知光照
- **方法**: 神经场 + 显式BRDF

**NeRFactor优势**: 唯一支持 (1)单一未知光照 + (2)显式可见性 + (3)学习BRDF

## 技术细节补充

### Rusinkiewicz坐标转换
```
输入: (n, ω_i, ω_o)
1. h = normalize(ω_i + ω_o)  // 半角向量
2. 旋转到 n = [0,0,1]
3. φ_d = atan2(ω_o.y, ω_o.x) - atan2(ω_i.y, ω_i.x)
4. θ_h = acos(h.z)
5. θ_d = acos(ω_o.z)
输出: (φ_d, θ_h, θ_d)
```

### 反照率约束推导
```
Ward & Shakespeare (1998): 反照率 ∈ [0.03, 0.8]
网络输出: sigmoid(x) ∈ [0, 1]
映射: a = 0.77 · sigmoid(x) + 0.03
```

### 可见性更新策略
```
每个训练批次:
  For each x_surf:
    采样 512个光照方向 ω_i
    查询 f_v(x_surf, ω_i)
    对比 v_a(x_surf, ω_i) (从NeRF追踪)
    反向传播梯度
```

### 光照梯度惩罚的作用
**实验** (消融):
- 无惩罚: 高频噪声 (图S2 B)
- λ₇=5×10⁻⁶: 平滑但保留主光源 (图4)
- λ₇>10⁻⁵: 过度平滑，丢失细节
