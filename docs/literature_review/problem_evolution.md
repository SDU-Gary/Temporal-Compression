# 神经渲染与光照压缩问题演变脉络

## 总览

本文档从**问题驱动**的视角，梳理神经渲染与光照压缩领域41年来核心问题的演变历程，揭示每个时代的技术瓶颈如何催生下一代解决方案。

**核心洞察**: 技术进步本质上是对前代问题的回应，每个里程碑工作都在解决特定瓶颈的同时引入新的挑战。

---

## 问题演变总图

```
1984-2002: 如何快速渲染真实场景?
   ↓ (Volume Rendering, Light Field, PRT)
2013-2019: 如何用神经网络紧凑表示场景?
   ↓ (SRN, DeepSDF, LLFF)
2020: 如何从2D图像重建高质量3D场景?
   ↓ (NeRF)
2021: 如何提升质量/速度/泛化性?
   ↓ (mip-NeRF, NeRF-W, pixelNeRF)
2022: 如何从小时级训练到秒级训练?
   ↓ (Instant NGP, Neural PRT)
2022-2023: 如何建模动态场景与时变光照?
   ↓ (K-Planes, NeRV, NRC)
2024-2025: 如何极致压缩光照数据?
   ↓ (Gaussian Compression)
2025+: 如何压缩与解压多时刻光照?
   ↓ (研究主题)
```

## Phase 1 (1984-2002): 经典渲染的质量-速度困境

### 核心问题: 真实感 vs. 实时性

#### 问题1.1: 体积数据如何高效渲染?
**时间**: 1984
**问题描述**:
- 体积数据(CT扫描, 烟雾)无法用传统光栅化
- 光线追踪计算量巨大(O(n³)采样)

**解决方案**: Volume Rendering [Kajiya'84]
- 体积渲染方程: C = ∫ T(t)σ(t)c(t)dt
- 物理正确的光传输模型

**引入新问题**:
- ❌ 仍然太慢(每帧数分钟)
- ❌ 需要密集体素存储

---

#### 问题1.2: 新视角合成如何避免3D重建?
**时间**: 1996
**问题描述**:
- 传统pipeline: 2D图像 → 3D重建 → 新视角渲染
- 3D重建困难(对应问题, 遮挡)

**解决方案**: Light Field Rendering [Levoy&Hanrahan'96]
- 7D全光函数 → 5D光场(无遮挡假设)
- 直接从密集采样插值新视角

**引入新问题**:
- ❌ 采样需求巨大(4D空间)
- ❌ 存储爆炸(GB级光场)
- ❌ 仅适用于静态场景

---

#### 问题1.3: 动态光照如何实时全局光照?
**时间**: 2002
**问题描述**:
- 实时渲染无法计算多次反弹
- 动态光照需要每帧重新计算

**解决方案**: Precomputed Radiance Transfer (PRT) [Sloan'02]
- 预计算传输矩阵T: E = TL
- 球谐基函数解耦光传输与光源
- 运行时仅需矩阵-向量乘法

**引入新问题**:
- ❌ 仅支持低频光照(球谐9阶~25系数)
- ❌ 预计算时间长(数小时)
- ❌ 存储需求大(每顶点/探针T矩阵)
- ❌ 静态几何假设

**问题演变**:
```
体积渲染太慢
  ↓
光场存储太大
  ↓
PRT预计算时间长+存储大
  ↓
如何紧凑表示?  ← 引向Phase 2
```

---

## Phase 2 (2013-2019): 神经网络的表示能力探索

### 核心问题: 离散 vs. 连续表示

#### 问题2.1: 3D数据结构如何高效存储?
**时间**: 2013
**问题描述**:
- 密集体素: O(n³)空间复杂度
- 八叉树: 仍需大量节点

**解决方案**: VoxelHashing [Nießner'13]
- 哈希表稀疏存储
- O(1)访问时间

**影响**: 启发Instant NGP的哈希编码(2022)

---

#### 问题2.2: MLP为何学不好高频细节?
**时间**: 2018
**问题描述**:
- MLP优先拟合低频分量
- 高频细节需要极深网络或大量训练

**解决方案**: Spectral Bias理论 [Rahaman'18]
- **发现**: MLP的梯度下降天然偏向低频
- **数学解释**: 傅里叶域中低频基函数梯度大

**引入新问题**:
- ❓ 如何让MLP学习高频? ← 催生位置编码

**影响**: 深远的理论基础，直接启发NeRF(2020)

---

#### 问题2.3: 如何用神经网络表示3D形状?
**时间**: 2019
**问题描述**:
- 传统表示(mesh, voxel, point cloud)离散
- 难以优化, 拓扑固定

**解决方案**: 神经隐式表示
- **DeepSDF** [Park'19]: f_θ: x → SDF
- **SRN** [Sitzmann'19]: f_θ: x → RGB (表面)
- **Occupancy Networks** [Mescheder'19]: f_θ: x → occupancy

**引入新问题**:
- ❌ 需要3D ground truth (SDF, occupancy)
- ❌ 仅建模单一表面
- ❌ 无法从2D监督学习

**问题演变**:
```
如何从2D图像学习3D?
  ↓
需要可微渲染器连接3D→2D
  ↓
体积渲染 + 神经隐式  ← 引向NeRF
```

## Phase 3 (2020): NeRF的三大突破与三大瓶颈

### 核心问题: 2D监督 + 3D重建 + 连续表示

#### 问题3.1: 如何从2D图像学习连续5D场景表示?
**时间**: 2020
**问题描述**:
- 传统3D重建需要depth/pose/calibration
- 离散表示(voxel)分辨率受限

**NeRF解决方案** [Mildenhall'20]:
1. **5D函数**: F_Θ: (x,y,z,θ,φ) → (σ, RGB)
2. **体积渲染**: 可微分2D→3D连接
3. **位置编码**: 克服频谱偏差

**技术细节**:
```
γ(p) = [sin(2^0πp), cos(2^0πp), ..., sin(2^(L-1)πp), cos(2^(L-1)πp)]
```
- 60维编码(位置10层+方向4层)
- MLP: 8层×256神经元(密度) + 1层×128(颜色)

**性能**:
- PSNR ~31 dB (Lego)
- 训练: 1-2天(100-300K步)
- 渲染: 30秒/帧

---

#### NeRF引入的三大瓶颈

##### 瓶颈3.1: 训练时间长 (1-2天)
**根源**:
- 每次迭代需要采样64-128条光线
- 每条光线192个点(64粗+128细)
- MLP评估次数: 64光线×192点×2网络 = 24,576次/iter
- 总计: 100K iter × 24K = 24亿次前向传播

**催生**:
- NSVF'20: 稀疏体素加速
- Instant NGP'22: 哈希编码 (1000×加速)

---

##### 瓶颈3.2: 渲染速度慢 (30秒/帧)
**根源**:
- 每像素需要采样192个点
- 1920×1080 = 2M像素 → 384M次MLP评估
- MLP太深太宽(8层×256)

**催生**:
- Plenoctrees'21: 预计算体素球谐
- Instant NGP'22: 小MLP (2层×64)
- Light Field Networks'21: 单次评估无积分

---

##### 瓶颈3.3: 光照隐式编码
**根源**:
- RGB直接预测,光照"烘焙"在网络中
- 无法分离几何/材质/光照
- 不支持重光照

**催生**:
- NeRF-W'21: 外观嵌入
- NeRFactor'21: BRDF分解
- Neural PRT'22: 传输算子

---

## Phase 4 (2021): NeRF的三大扩展方向

### 核心问题: 质量, 泛化, 光照控制

#### 问题4.1: 如何消除锯齿与尺度不一致?
**时间**: 2021
**问题描述**:
- NeRF在不同距离产生锯齿
- 位置编码固定频率,不随距离调整

**解决方案**: mip-NeRF [Barron'21]
- 用圆锥代替光线
- 集成位置编码(IPE): 编码3D高斯而非点

**性能**: PSNR提升0.5-2 dB, 速度快7%

**引入新问题**:
- ❌ 仍需1-2天训练
- ❌ 仍不支持重光照

---

#### 问题4.2: 如何处理野外场景的光照变化?
**时间**: 2021
**问题描述**:
- 同一场景不同照片光照不同(时间, 天气)
- NeRF假设静态光照,产生模糊

**解决方案**: NeRF-W [Martin-Brualla'21]
- **外观嵌入**: 每张图像一个潜在码ℓ^(a)
- **瞬态嵌入**: 建模动态对象ℓ^(τ)
- **不确定性**: 预测per-pixel不确定度

**架构**:
```
F_Θ: (x,y,z,θ,φ, ℓ^(a)) → (σ, RGB_static, RGB_transient, β)
```

**影响**: 光照变化建模的早期探索

**引入新问题**:
- ❓ 外观嵌入是什么? 能否解释为光照?
- ❓ 如何显式建模光源?

---

#### 问题4.3: 如何实现重光照?
**时间**: 2021
**问题描述**:
- NeRF RGB"烘焙"了光照
- 无法改变光源渲染新效果

**解决方案**: NeRFactor [Zhang'21]
- **几何蒸馏**: NeRF → 表面点
- **BRDF分解**: Lambertian + 学习镜面
- **可见性MLP**: 预测阴影
- **数据驱动BRDF先验**: 从MERL数据集学习

**Pipeline**:
```
NeRF预训练 → 表面法线MLP
  ↓
可见性MLP(阴影) + 反照率MLP + BRDF Identity MLP
  ↓
渲染方程: L = ∫ BRDF · L_env · V · max(n·ω,0) dω
```

**性能**:
- 重光照PSNR 25-30 dB
- 支持材质编辑

**引入新问题**:
- ❌ NeRF预训练仍需1-2天
- ❌ 单一光照状态,不支持多时刻
- ❓ 如何快速烘焙多个光照?

---

## Phase 5 (2022): 效率革命与物理融合

### 核心问题: 从小时到秒 + 物理正确性

#### 问题5.1: 如何实现秒级训练NeRF?
**时间**: 2022
**问题描述**:
- NeRF训练1-2天不可接受
- MLP评估是瓶颈(深网络+位置编码)

**Instant NGP解决方案** [Müller'22]:

##### 核心创新1: 多分辨率哈希编码
- **替代**: 60维位置编码 → 32维哈希查表
- **结构**: 16层几何级数分辨率
- **哈希函数**: h(x) = (⊕x_i π_i) mod T
- **查找**: O(1)时间, 无MLP评估

##### 核心创新2: 极小MLP
- 密度网络: 1层×64 (vs. NeRF 8层×256)
- 颜色网络: 2层×64 (vs. NeRF 5层×128)
- 参数量相当,但FLOPs大幅减少

##### 核心创新3: 完全融合CUDA内核
- 整个forward/backward用单个kernel
- 权重存寄存器,激活存共享内存
- 避免global memory访问

**性能突破**:
- 训练: 5秒(达NeRF质量), 15秒(超越), 1分钟(近mip-NeRF)
- **1000×加速**
- 渲染: 60 FPS @ 1080p

**技术影响**:
- 开启实时神经渲染时代
- 证明混合表示(显式哈希+隐式MLP)优势

**引入新问题**:
- ❓ 如何适应PRT等物理模型?
- ❓ 如何处理动态光照?

---

#### 问题5.2: PRT如何利用神经网络加速?
**时间**: 2022
**问题描述**:
- 传统PRT预计算T矩阵: 数小时-数天
- 存储T矩阵: 每探针/顶点KB级
- 仅支持低频(9-25 SH系数)

**Neural PRT解决方案** [Rainer'22]:

##### 核心创新1: 神经传输算子
```
T_Θ: L_env → E_scene
```
- 替代: 存储T矩阵 → 学习神经算子

##### 核心创新2: 算子因式分解
```
T = SE
S: L_env → L_visible (Slicing, 可见性)
E: L_visible → E_scene (Environment mapping)
```
- 利用PRT理论指导神经架构

##### 核心创新3: ViT架构
- Image Encoder: 提取环境贴图特征
- Vision Transformer: 全局注意力
- Image Decoder: 生成场景光照

**性能**:
- 烘焙: 2-10分钟 (vs. 数小时)
- 推理: 5-30 ms
- PSNR: 36-44 dB
- 支持高频细节

**技术融合**:
- 经典PRT理论 + 现代Transformer
- 物理约束 + 数据驱动

**引入新问题**:
- ❓ 如何处理动态几何?
- ❓ 如何支持多时刻光照?

---

#### 问题5.3: 路径追踪如何实时去噪?
**时间**: 2021
**问题描述**:
- 实时路径追踪: 每像素1-4 spp → 噪声大
- 传统去噪: 时间滞后, 闪烁

**Neural Radiance Caching解决方案** [Müller'21]:

##### 核心创新1: 在线神经缓存
- 场景划分区域,每区域小MLP缓存辐射度
- 在线训练: 渲染时同步更新网络

##### 核心创新2: 自训练机制
```
路径: x_0 → x_1 → ... → x_k (缓存查询) → y_1 → ... → y_m (终止)
目标: L_target(x_i) = Cache(terminal vertex)
```
- Q-learning思想: 用终点缓存值训练中间点

##### 核心创新3: 完全融合网络
- 7层×64神经元,无偏置
- 权重→寄存器,激活→共享内存
- 9× faster than TensorFlow

##### 核心创新4: 路径终止启发式
```
a(x_1...x_n) = (Σ√(d²/p|cosθ|))²
终止条件: a > 0.01·a_0
```

**性能**:
- 60+ FPS所有测试场景
- 13.6× average speedup
- MRSE降低1-2个数量级

**技术范式**:
- 在线学习 (vs. 离线预训练)
- 自训练 (vs. 监督学习)

**引入新问题**:
- ❓ 如何扩展到时变光照?
- ❓ 如何利用时间相干性?

## Phase 6 (2022-2023): 动态场景与时空表示

### 核心问题: 静态 → 动态, 3D → 4D

#### 问题6.1: 视频如何用神经网络压缩?
**时间**: 2021-2022
**问题描述**:
- H.264/H.265复杂编解码
- 难以GPU加速
- 固定码率

**NeRV解决方案** [Chen'21]:
- **帧索引输入**: t → MLP → RGB帧
- **上采样架构**: NeRV Block = Conv + PixelShuffle
- **网络权重 = 视频**

**性能**:
- 压缩比: 10-100×
- 解码: 10-30× faster than H.264
- 可微: 支持视频编辑

**概念启发**:
- 时间可以用神经网络隐式编码
- 连续时间表示 vs. 离散帧

---

#### 问题6.2: 动态NeRF如何高效建模?
**时间**: 2023
**问题描述**:
- 时空4D函数: f(x,y,z,t)
- 直接扩展NeRF → 参数爆炸

**K-Planes解决方案** [Fridovich-Keil'23]:

##### 核心创新: 6平面分解
```
空间: XY, XZ, YZ (3个)
动态: XY_t, XZ_t, YZ_t (3个)
```
- **时空解耦**: 时间平面独立
- **外观平面**: 建模光照变化

##### 查询流程:
```
(x,y,z,t) → 投影到6平面
  ↓
双线性采样 → 6个特征
  ↓
逐元素相乘 → 聚合
  ↓
小MLP → (σ, RGB)
```

**性能**:
- 动态场景PSNR 30-35 dB
- 训练: 分钟级
- 支持时空插值

**技术意义**:
- 显式4D表示
- 时空解耦思想
- 外观平面 → 光照建模潜力

**引入新问题**:
- ❓ 如何专门建模光照(而非整体外观)?
- ❓ 如何压缩多时刻数据?

## Phase 7 (2024-2025): 神经压缩的极致追求

### 核心问题: 光照数据的存储与内存爆炸

#### 问题7.1: 光照探针如何高效压缩?
**时间**: 2025
**问题描述**:
- **存储爆炸**: 15,000探针 × 27 SH系数 × 4 bytes = 1.6 MB (单场景)
- **运行时内存**: 密集3D纹理(VLM/APV) → GB级
- **传统PCA局限**:
  - 线性降维,复杂场景效果差
  - CPCA/BPCA: 块边界不连续
  - 压缩比低(1:15左右)

**Gaussian Compression解决方案** [Zhou'25]:

##### 核心创新1: 高斯+MLP混合表示
```
K个3D高斯: G_j(x) = exp(-½(x-μ_j)ᵀΣ_j⁻¹(x-μ_j))
每个高斯携带潜在码: F_j ∈ R^D

探针p的潜在特征:
F(p) = Σ_{j:p∈R(G_j)} F_j · G_j(p)

MLP解码:
L(p) = Φ([F(p), p]; θ)
```

**优势**:
- 高斯自动适应探针分布
- 非线性压缩
- 空间相关性显式建模

##### 核心创新2: 级联光照体积(CLV)
```
4级空间级联: 2m, 4m, 8m, 32m块
每帧动态更新: ≤64块
八叉树: 快速定位探针
LRU缓存: 时间局部性
滚动索引: 避免冗余更新
```

**解决**:
- 避免密集3D纹理
- 运行时内存: KB级(vs. GB级)

##### 核心创新3: 自适应量化
```
10-bit量化: ŝ = ⌊(s-s_min)/(s_max-s_min)·1023⌉
粗调: 保留原始参数, Straight-through估计器
精调: 冻结量化高斯, 仅训练MLP适应
```

**性能突破**:
- **压缩比**: 1:50
- **质量**: PSNR 42.91 dB (低压缩), 44.82 dB (高压缩)
- **vs. CPCA**: PSNR +3.8 dB, MSE -78.6%
- **解压缩**: 0.48 ms (5%高斯)
- **内存**: 50 KB

**技术范式转变**:
```
PCA线性降维
  ↓
MBD(移动基分解, 半显式)
  ↓
Gaussian Compression(高斯基+神经解码)
```

**未来方向(论文明确提出)**:
1. **Time of Day (TOD)**: 压缩全天光照变化
2. **图像域优化**: 直接优化渲染结果
3. **通用应用**: 空间信号编码, 点云压缩

**引入新问题 (直接对应研究主题)**:
- ❓ 如何扩展到4D高斯(空间3D+时间1D)?
- ❓ 如何联合压缩多时刻探针?
- ❓ 如何建模时间相干性?
- ❓ 如何实现时空级联?

## 问题收敛: 面向研究主题的核心挑战

### 终极问题: 多时刻光照的层次化神经压缩

从41年技术演变中提炼的**五大核心挑战**:

---

#### 挑战1: 时间维度爆炸
**问题描述**:
- T个时刻 × N个探针 × D维SH → TND倍数据
- 示例: 24小时每小时1个时刻 → 24× 存储

**历史尝试**:
- NeRF-W'21: 外观嵌入(每图像一个码) - 无时间连续性
- K-Planes'23: 时间平面 - 未专门针对光照
- NeRV'22: 帧索引输入 - 视频领域

**待解决**:
- ✓ 如何提取时间冗余? (空间变化慢,时间变化也慢)
- ✓ 如何共享空间结构? (同一场景,仅光照变)
- ✓ 如何建模太阳轨迹等先验?

**可能方向**:
```
方案A: 4D高斯
  G_j(x,y,z,t) with 时变潜在码F_j(t)

方案B: 时空分离
  空间高斯(固定) × 时间MLP(可学习)

方案C: 时间聚类
  K-Means时刻 → 每类共享高斯 → 时间插值
```

---

#### 挑战2: 物理正确性 vs. 数据驱动
**问题描述**:
- 纯数据驱动: 丢失物理约束(能量守恒,互易性)
- 纯物理模拟: 无法处理复杂间接光照

**历史尝试**:
- PRT'02: 物理正确但低频
- Neural PRT'22: 算子因式分解保留物理结构
- NeRFactor'21: BRDF物理模型 + 数据驱动

**待解决**:
- ✓ 如何约束神经网络遵循光传输方程?
- ✓ 如何保证时间连续性(光源移动连续)?

**可能方向**:
```
物理嵌入神经网络:
  L_loss = L_recon + λ_phys·L_physics

  L_physics = ||∇·I||² (辐射度守恒)
            + ||BRDF(ω_i,ω_o) - BRDF(ω_o,ω_i)||² (互易性)
            + 时间平滑正则
```

---

#### 挑战3: 层次化表示
**问题描述**:
- 光照变化多尺度: 全局(太阳方向) + 局部(阴影)
- 时间变化多尺度: 快速(云) + 慢速(季节)

**历史尝试**:
- Instant NGP'22: 16层空间分辨率
- CLV'25: 4级空间级联
- K-Planes'23: 平面分辨率可调

**待解决**:
- ✓ 如何设计时空双层次?
- ✓ 如何自适应分配分辨率?

**可能方向**:
```
时空级联:
  空间: 4级(2m, 4m, 8m, 32m)
  ×
  时间: 3级(小时, 天, 季节)

  = 12个时空体积

  查询(x,y,z,t):
    空间级别 = f(距离视点)
    时间级别 = f(变化速率)
    → 选择对应体积插值
```

---

#### 挑战4: 实时解压缩
**问题描述**:
- 渲染每帧需要查询数千探针
- 每个探针需要解压(高斯查找+MLP推理)
- 多时刻: 还需时间插值

**历史尝试**:
- Instant NGP'22: 完全融合CUDA (1000×加速)
- NRC'21: 在线训练+推理0.7ms
- Gaussian Compression'25: 0.48ms解压

**待解决**:
- ✓ 如何<1ms解压多时刻?
- ✓ 如何利用时间相干性(帧间复用)?
- ✓ 如何GPU高效实现?

**可能方向**:
```
Temporal LRU Cache:
  缓存: (空间块ID, 时间区间) → 解压结果

  每帧:
    if 时间变化小: 复用缓存(0 cost)
    else: 仅解压变化块(部分cost)

  + 预测: 提前解压下一时刻
  + 异步: 后台线程解压,主线程查询
```

---

#### 挑战5: 可编辑性
**问题描述**:
- 压缩后能否编辑光源?
- 能否插值新时刻(如中午12:30)?

**历史尝试**:
- NeRFactor'21: 支持光源编辑
- Neural PRT'22: 支持任意环境贴图
- K-Planes'23: 时空插值

**待解决**:
- ✓ 压缩表示的可解释性
- ✓ 解耦光源/几何/材质
- ✓ 时间平滑插值

**可能方向**:
```
分解表示:
  L_indirect(x,t) = T(x) ⊗ L_env(t)

  T(x): 空间传输(高斯+MLP, 静态)
  L_env(t): 时变光源(球谐系数, 低维)

  编辑: 直接修改L_env(t)
  插值: 球谐空间SLERP
```

### 核心贡献预期

**问题**: 如何以极致压缩比,存储与实时解压多时刻光照?

**技术栈**(基于41年演变):
1. **表示**: 4D高斯 (Gaussian Compression'25扩展)
2. **编码**: 时空哈希/平面 (Instant NGP'22 + K-Planes'23)
3. **压缩**: 高斯+MLP混合 + 时间聚类 (Gaussian Compression'25 + NeRV'22)
4. **解压**: 时空级联CLV + LRU缓存 (Gaussian Compression CLV'25扩展)
5. **物理**: 传输算子约束 (Neural PRT'22)
6. **优化**: 完全融合CUDA (Instant NGP'22 + NRC'21)

**预期突破**:
- 压缩比: 1:100+ (vs. 单时刻1:50)
- 质量: PSNR 40+ dB (保持高质量)
- 解压: <1ms (时间相干性加速)
- 可编辑: 支持光源插值与编辑

3. **遗留**: 引入新维度挑战

- **技术基础充分**: Gaussian Compression'25已解决单时刻
