# NeRV: Neural Reflectance and Visibility Fields for Relighting and View Synthesis

## 基本信息
- **作者**: Pratul P. Srinivasan, Boyang Deng, Xiuming Zhang, Matthew Tancik, Ben Mildenhall, Jonathan T. Barron
- **机构**: Google Research, MIT, UC Berkeley
- **发表**: arXiv:2012.03927v1 [cs.CV] 7 Dec 2020
- **类型**: 神经渲染 + 可重光照 + 全局光照

## 解决的核心问题

### 主要问题
1. **NeRF无法重光照**: NeRF仅建模出射辐射度，无法分离入射光和材质
2. **光传输计算效率**: NeRF连续体积表示中模拟光传输计算昂贵
3. **可见性查询**: 密集采样体积密度以计算可见性在环境光照下不可行
4. **全局光照**: 单次反弹间接光照需要三次方复杂度采样

### 研究配置
- **输入**: 已知非受限光照下的多视角图像
- **输出**: 可从任意视角、任意光照条件渲染的3D表示
- **光照条件**: 环境光照 + 一次反弹间接光照
- **目标**: 物理正确的光传输 + 高效训练

## 技术方法与Pipeline

### 核心创新: Neural Visibility Fields (神经可见性场)

**动机**: 暴力光线追踪不可行
- **直接光照**: n个相机光线样本 × l个光源 → O(n²l) 复杂度
- **一次反弹间接**: n × d个方向 × l → O(n³dl) 复杂度 (Petaflop级!)

**解决方案**: 用MLP近似可见性查询

```
MLPφ: (x, ω) → (Ṽφ, D̃φ)

输入: 3D位置x, 方向ω
输出:
  - Ṽφ: 环境光照可见性近似
  - D̃φ: 期望终止深度近似
```

### NeRV完整表示

#### 三个MLP
1. **Shape MLP** (形状):
```
MLPθ: x → σ
```
- 输入: 3D位置x
- 输出: 体积密度σ

2. **Reflectance MLP** (反射率):
```
MLPψ: x → (a, γ)
```
- 输入: 3D位置x
- 输出:
  - a: 漫反射RGB反照率
  - γ: 镜面粗糙度

3. **Visibility MLP** (可见性):
```
MLPφ: (x, ω) → (Ṽφ, D̃φ)
```
- 输入: 3D位置x, 方向ω
- 输出:
  - Ṽφ: 可见性
  - D̃φ: 期望终止深度

#### 表面法线
```
n = -∇x MLPθ(x) / ||∇x MLPθ(x)||
```
- **解析计算**: 密度梯度的负归一化
- **vs. MLP输出**: 更准确的表面法线

### 光传输模拟

#### 体积渲染积分 (完整形式)
```
L(c, ωo) = ∫₀^∞ V(x(t), c) σ(x(t)) Lr(x(t), ωo) dt
```
其中:
- **V(x(t), c)**: 到相机的可见性 (Eq. 2)
- **σ(x(t))**: 体积密度
- **Lr(x(t), ωo)**: 反射辐射度

#### 反射辐射度分解
```
Lr(x, ωo) = ∫_S Li(x, ωi) R(x, ωi, ωo) dωi
```
- **Li**: 入射辐射度 = Le (直接) + L (间接)
- **R**: BRDF反射函数 (microfacet模型)

#### 直接光照 (Eq. 9)

**入射直接光**:
```
Le(x, ωi) = V(x, ωi) E(x, -ωi)
```
- **E**: 已知环境贴图
- **V(x, ωi)**: 环境可见性 → 用Ṽφ近似

**简化后的直接光照积分**:
```
L_direct(c, ωo) = ∫₀^∞ V(x(t), c) σ(x(t))
                  ∫_S Ṽφ(x(t), ωi) E(x(t), -ωi) R(x(t), ωi, ωo) dωi dt
```

**复杂度**: O(n²) → O(n) (线性!)

#### 间接光照 (Eq. 12-13)

**两个近似**:
1. **硬表面近似**: 外层积分用单点评估
```
t' = D(c, -ωo)  // 期望终止深度
```

2. **一次反弹限制**: 内层递归用单次散射
```
t'' = D̃φ(x(t'), ωi)  // 二次交点深度 (用MLP)
x'(t'') = x(t') + t'' ωi
```

**完整间接光照**:
```
L_indirect = ∫∫_S Ṽφ(x'(t''), ω'i) E(x'(t''), -ω'i)
                  R(x'(t''), ω'i, -ωi) dω'i
                  R(x(t'), ωi, ωo) dωi
```

**复杂度**: O(n³d) → O(nd) (线性!)

#### 完整体积渲染方程 (Eq. 14)
```
L(c, ωo) = L_direct + L_indirect
```

### BRDF模型 (Microfacet)

```
R(x, ωi, ωo) = D(h,n,γ)F(ωi,h)G(ωi,ωo,γ) / (4(n·ωo))
               + (n·ωi)(1-F(ωi,h))a/π
```

**组件**:
- **D**: GGX法线分布函数
- **F**: Fresnel项 (F0=0.04, 介电材质)
- **G**: 几何遮蔽项
- **a**: 漫反射反照率
- **γ**: 粗糙度

### 渲染流程

**输入**: 相机射线 x(t) = c - tωo

**Step 1**: 沿射线采样 (256个分层样本)
```
σ = MLPθ(x(t))
n = -∇x MLPθ(x(t))
(a, γ) = MLPψ(x(t))
```

**Step 2**: 每点直接光照着色
```
- 12×24网格采样环境光方向ωi
- 查询Ṽφ(x(t), ωi)
- 计算R(x(t), ωi, ωo)
- 球面积分 → 直接光照贡献
```

**Step 3**: 间接光照着色
```
- 计算t' = D(c, -ωo) (用Step 1密度样本)
- 上半球采样128个方向ωi
- 查询t'' = D̃φ(x(t'), ωi)
- 二次交点x'(t'') = x(t') + t'' ωi
- 按Step 2为每个x'(t'')计算直接光
- 乘以R(x(t'), ωi, ωo)并球面积分 → 间接贡献
```

**Step 4**: 体积渲染合成
```
L(c, ωo) = Σ_t V(x(t), c) α(σ(x(t))δ) Lr(x(t), ωo)
V(x(t), c) = exp(-Σ_{s<t} σ(x(s))δ)
α(z) = 1 - exp(-z)
```

### 训练与损失

#### 损失函数 (Eq. 16)
```
L = Σ_{r∈R} ||τ(L̃(r)) - τ(L(r))||²₂
  + λ Σ_{r'∈R'∪R,t} (||Ṽφ(r'(t)) - Vθ(r'(t))||²₂
                    + ||D̃φ(r'(t)) - Dθ(r'(t))||²₂)
```

**组件**:
1. **图像重建损失**: tone-mapped L2
   - τ(x) = x/(1+x): tone-mapping
   - L(r): 真实像素颜色
   - L̃(r): 预测颜色

2. **可见性监督**:
   - **R**: 512条随机像素射线
   - **R'**: 256条随机体积相交射线
   - **Vθ, Dθ**: Shape MLP隐含的真实值 (Eq. 5-6)
   - **Ṽφ, D̃φ**: Visibility MLP预测
   - **λ = 20**: 可见性损失权重
   - **stop gradient**: Vθ, Dθ不反向传播到Shape MLP

#### 真实可见性与深度 (Eq. 5-6)
```
V(x, ω) = exp(-∫₀^∞ σ(x + sω) ds)

D(x, ω) = ∫₀^∞ exp(-∫₀^t σ(x + sω) ds) t σ(x + tω) dt
```

#### 网络架构
- **Shape & Reflectance MLP**: 8层FC, 256通道, ReLU
- **Visibility MLP**:
  - 8层FC (256ch) 编码x → 8维特征
  - 拼接编码后的ω
  - 4层FC (128ch) → (Ṽ, D̃)
- **位置编码**: NeRF位置编码
  - x: 最大频率2⁷
  - ω: 最大频率2⁴

#### 优化配置
- **优化器**: Adam
- **学习率**: 10⁻⁵ → 10⁻⁶ (指数衰减)
- **Batch**: 512像素射线
- **训练**: 1M iterations, 1天 (128 TPU cores)

## 实验设置与结果

### 数据集

#### 9个训练数据集 (3场景 × 3光照)

**场景**:
1. Hotdogs
2. Lego
3. Armadillo

**光照条件**:
1. **Single Point**: 单个白色点光源 (半球随机)
2. **Colorful + Point**: 随机点光 + 8个固定彩色点光
3. **Ambient + Point**: 随机点光 + 灰色环境光

**每个数据集**: 150张训练图像

**测试集**: 150张新视角 + 新光照图像

### 性能对比

#### Hotdogs场景 (PSNR ↑ / MS-SSIM ↑)

| 训练光照 | Single Point | Colorful + Point | Ambient + Point |
|----------|-------------|------------------|-----------------|
| NLT | - | - | 23.57 / 0.851 |
| NeRF+LE | 19.96 / 0.868 | 17.88 / 0.758 | 20.72 / 0.869 |
| NeRF+Env | 19.94 / 0.863 | 19.17 / 0.824 | 20.56 / 0.864 |

| **NeRV, Trace** | 23.76 / **0.863** | 24.24 / 0.886 | 25.06 / 0.892 |

| Bi et al. | 22.89 / 0.897 | 22.83 / 0.890 | 18.10 / 0.783 |
| **NeRV, NVF** | 22.78 / 0.866 | **23.82** / 0.899 | 23.32 / 0.894 |
| **NeRV, Trace** | **23.16** / **0.883** | 24.18 / **0.925** | **23.79** / **0.923** |

#### Armadillo场景

| 训练光照 | Single Point | Colorful + Point | Ambient + Point |
|----------|-------------|------------------|-----------------|
| Bi et al. | 22.35 / 0.894 | 21.06 / 0.892 | 19.93 / 0.842 |

**关键发现**:
1. **复杂光照**: NeRV在Colorful+Point和Ambient+Point大幅超越Bi et al.
2. **简单光照**: NeRV与Bi et al.性能相当 (Single Point)
3. **潜在编码失败**: NeRF+LE和NeRF+Env无法泛化到新光照

### 消融实验 (Table 2, Ambient+Point)

| 变体 | Hotdogs | Lego | Armadillo |
|------|---------|------|-----------|
| No Indirect | 24.43 / 0.861 | 23.06 / 0.888 | 21.27 / 0.878 |
| MLP Normals | 25.60 / 0.893 | 23.18 / 0.886 | 22.40 / 0.891 |
| **NVF** | **25.14 / 0.892** | 23.32 / 0.894 | **22.80 / 0.897** |
| **Trace** | 25.06 / 0.892 | **23.79 / 0.923** | 22.81 / 0.895 |

**结论**:
1. **间接光照**: 提升显著 (+0.7~1.5 dB)
2. **解析法线**: 比MLP预测法线更准确
3. **测试时追踪**: Trace版本稍优但更慢

### 两个NeRV版本

**NeRV, NVF** (Neural Visibility Fields):
- 训练和测试都用Visibility MLP近似
- 更快
- 阴影略微模糊

**NeRV, Trace** (Test-time Tracing):
- 训练用Visibility MLP
- 测试用暴力追踪计算点光源可见性
- 更锐利的阴影
- 更慢

## 技术突破与贡献

### 1. Neural Visibility Fields创新
- **查表范式**: MLP作为可见性查找表
- **联合优化**: Visibility MLP与Shape MLP同步优化
- **自监督**: 仅从Shape MLP隐含的可见性学习

### 2. 复杂光照支持
- **环境光照**: 全方向入射光
- **一次反弹GI**: 间接光照模拟
- **vs. Neural Reflectance Fields**: 仅支持单点光

### 3. 效率突破
- **暴力方法**: Petaflop级计算 (单光线)
- **NeRV**: 线性复杂度 O(n)
- **训练可行**: 10亿条光线 × 可行时间

### 4. 物理正确性
- **Microfacet BRDF**: 工业标准PBR模型
- **体积渲染**: 物理正确光传输
- **解析法线**: 梯度计算保证几何一致性

### 5. 分解表示
- **几何**: Shape MLP (σ)
- **材质**: Reflectance MLP (a, γ, n)
- **可见性**: Visibility MLP (V, D)
- **光照**: 外部环境贴图E

## 局限性

### 1. 一次反弹限制
- 仅模拟单次间接光照
- 多次反弹会导致复杂度爆炸
- 焦散等高阶效应无法捕捉

### 2. 硬表面近似
- 期望深度单点评估
- 半透明/体积效果不准确
- 适合不透明物体

### 3. 训练成本
- **1M iterations**: 1天 (128 TPU cores)
- **场景特定**: 每场景独立训练
- **无泛化**: 无法跨场景

### 4. 测试时光照限制
- **已知光照**: 需要环境贴图E
- **无光照估计**: 不能从图像反推光照

### 5. 可见性近似误差
- MLP近似 vs. 真实可见性
- 阴影略微模糊 (NVF版本)
- Trace版本速度慢

## 技术细节补充

### Visibility MLP监督详细流程

**采样射线R'** (每iteration 256条):
```
1. 随机采样光线与体积相交
2. 沿每条光线双向采样
3. 采样点 + 随机方向 → 查询对
```

**计算真实值Vθ, Dθ**:
```
1. 沿方向密集采样n个点
2. 查询Shape MLP: σ₁, ..., σₙ
3. 数值积分Eq. 5-6 → Vθ, Dθ
```

**监督**:
```
L_vis = ||Ṽφ - stop_grad(Vθ)||²₂
      + ||D̃φ - stop_grad(Dθ)||²₂
```

### 渲染球面积分实现

**直接光照环境采样**:
- **网格**: 12×24 = 288方向
- **球谐**: 可选，但实验用网格

**间接光照重要性采样**:
- **上半球**: 128随机方向
- **BRDF重要性**: 未使用，均匀采样

### 对比方法详细

**NLT** (Neural Light Transport):
- **输入**: OLAT (每视角150张 × 光源数)
- **8× 数据**: vs. NeRV
- **代理几何**: NeRF + Marching Cubes
- **CNN**: 纹理空间卷积网络

**Bi et al.** (Neural Reflectance Fields):
- **相同架构**: Shape + Reflectance MLP
- **暴力追踪**: 每点到每光源密集采样
- **限制**: 仅单点光训练
- **测试**: 可多光源 (时间充裕)

**NeRF+LE/Env** (潜在编码):
- **NeRF-W变体**: 外观嵌入
- **LE**: PointNet编码光源
- **Env**: 展平环境贴图
- **失败**: 无物理光传输，无泛化

- **改进**: 光照-材质分离，可重光照
- **扩展**: 可见性场
- **保留**: 体积渲染框架

### vs. Neural PRT
- **共同**: 光照-传输分离思想
- **不同**:
  - NeRV: 任意光照 (环境贴图)
  - Neural PRT: PRT球谐基
- **互补**: NeRV可借鉴PRT分解

### vs. K-Planes
- **共同**: 神经场分解
- **不同**:
  - NeRV: 光照-材质-可见性
  - K-Planes: 空间-时间
- **潜在结合**: 时空 + 光照多维分解

### vs. Instant NGP
- **对比**:
  - NeRV: 可重光照但慢
  - NGP: 快但无光照分解
- **互补**: 哈希编码 + 光照分解

## 数学形式化总结

**NeRV表示**:
```
场景 = {MLPθ, MLPψ, MLPφ}

几何: σ = MLPθ(x)
法线: n = -∇x MLPθ(x) / ||∇x MLPθ(x)||
材质: (a, γ) = MLPψ(x)
可见性: (V, D) = MLPφ(x, ω)

渲染:
  L(c, ωo) = ∫ V(x,c) σ(x) [L_direct(x,ωo) + L_indirect(x,ωo)] dx

  L_direct = ∫ Ṽ(x,ωi) E(x,-ωi) R(x,ωi,ωo) dωi

  L_indirect = ∫∫ Ṽ(x',ω'i) E(x',-ω'i) R(x',ω'i,-ωi) R(x,ωi,ωo) dω'i dωi
               其中 x' = x + D̃(x,ωi)·ωi
```

**损失函数**:
```
L = L_recon + λ L_vis

L_recon = Σ ||τ(L̃) - τ(L)||²
L_vis = Σ (||Ṽ - Vθ||² + ||D̃ - Dθ||²)
```
