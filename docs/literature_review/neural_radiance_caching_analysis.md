# Real-time Neural Radiance Caching for Path Tracing

## 基本信息
- **作者**: Thomas Müller, Fabrice Rousselle, Jan Novák, Alexander Keller
- **机构**: NVIDIA
- **发表**: ACM SIGGRAPH 2021 (ACM Transactions on Graphics, Vol. 40, No. 4, August 2021)
- **项目**: 开源代码（tiny-cuda-nn框架）
- **类型**: 实时渲染 + 在线深度学习

## 解决的核心问题

### 主要问题
1. **实时路径追踪的间接光照噪声**: 直接光照可用ReSTIR降噪，但间接光照仍然噪声严重
2. **辐射缓存的传统难题**: 定位、插值、更新缓存点的复杂启发式
3. **神经网络泛化挑战**: 预训练网络难以泛化到未见过的动态场景
4. **实时训练性能瓶颈**: 神经网络训练/推理开销需控制在毫秒级

### 问题设定
- **输入**: 完全动态场景（光照、几何、材质、相机）
- **输出**: 低噪声、低偏差的路径追踪图像
- **预算**: 16.6ms/帧 (60 FPS)
- **假设**: 无预计算、无场景先验知识

## 技术方法与Pipeline

### 整体Pipeline

```
每帧渲染流程:
┌─────────────────────────────────┐
│ 1. 追踪短渲染路径 (每像素1条)      │
│    - 前几个顶点: 次事件估计(NEE)   │
│    - 终止到神经缓存 (启发式)       │
├─────────────────────────────────┤
│ 2. 扩展训练路径 (3%渲染路径)      │
│    - 延长后缀2-3个顶点            │
│    - 收集训练数据                 │
├─────────────────────────────────┤
│ 3. 在线训练神经缓存               │
│    - 4次梯度下降步骤              │
│    - 每批16384个样本              │
│    - 自训练机制                   │
├─────────────────────────────────┤
│ 4. 图像重建                      │
│    - 反向传播缓存辐射             │
│    - 累积路径贡献                 │
└─────────────────────────────────┘
```

### 核心创新1: 自训练（Self-training）

**传统方法问题**:
- 蒙特卡洛路径追踪训练目标 → 噪声大，收敛慢
- 预训练网络 → 难以泛化到动态场景

**自训练解决方案**:
```
训练路径: x_0 → x_1 → ... → x_k → y_1 → y_2 → ... → y_m
                    ↑          ↑                    ↑
                 渲染终止    训练后缀起点         训练终止

目标值来源:
For vertex x_i in [x_1, ..., x_k, y_1, ..., y_m]:
    L_target(x_i) = 缓存查询(terminal vertex)
                   通过路径传输到x_i
```

**优势**:
- **低噪声目标**: 用神经预测替代蒙特卡洛采样 → 减少方差，引入可控偏差
- **迭代多次弹射**: 每次训练增加1次弹射 → 逐步捕获全局光照
- **类似Q-learning**: 自举式学习，类似强化学习

**注入无偏估计** (u=1/16):
```python
if rand() < u:  # 1/16的训练路径
    L_target = 完整路径追踪(俄罗斯轮盘赌终止)
else:
    L_target = 缓存查询(启发式终止)
```

### 核心创新2: 完全融合神经网络 (Fully Fused NN)

**性能瓶颈分析**:
- 窄网络(64神经元): 内存带宽是瓶颈（非计算）
- 传统实现(TensorFlow): 大量全局内存访问

**完全融合策略**:
```
GPU内存层次利用:
Global Memory (VRAM)
    ↓ 仅读写输入/输出
Shared Memory (on-chip)
    ↓ 存储中间激活
Registers
    ↓ 存储权重矩阵块

优化关键:
1. 整个网络 = 单个CUDA kernel
2. 权重矩阵仅从全局内存加载1次
3. 中间激活常驻共享内存
4. 利用Tensor Core加速矩阵乘法
```

**实现细节** (Figure 6):
```
线程块划分:
- Batch分成128元素的块
- 每个线程块处理1个块
- 64×64权重矩阵适配寄存器
- 64×128激活适配共享内存

矩阵乘法:
- 16×16块 → Tensor Core
- 每个warp计算16×128块行
- 权重加载1次，激活多次复用
```

**性能对比** (Figure 7):
| 批量大小 | TensorFlow | 完全融合 | 加速比 |
|---------|-----------|---------|--------|
| 2^14 (训练) | ~2×10^7 元素/秒 | ~1.8×10^8 | ~9× |
| 2^21 (推理) | ~1.2×10^8 | ~1×10^9 | ~8× |

### 核心创新3: 混合输入编码

**编码选择原则**:
- **频率编码** (位置x): 处理大尺度空间变化
- **One-blob编码** (方向ω, 法线n, 粗糙度r): 处理局部变化
- **直接输入** (反照率α, 镜面反射β): 已近似线性

**具体配置** (Table 1):
```
位置 x ∈ R³:
  freq(x) = [sin(2^0·x), ..., sin(2^11·x)] ∈ R^(3×12)

散射方向 ω ∈ S²:
  sph(ω) → [θ, φ] ∈ [0,1]²
  oneb([θ,φ], k=4) ∈ R^(2×4)

表面法线 n ∈ S²:
  oneb(sph(n), k=4) ∈ R^(2×4)

粗糙度 r ∈ R:
  oneb(1-exp(-r)) ∈ R^4

反照率/镜面 α,β ∈ R³:
  id(α), id(β) ∈ R³×2

总维度: 36 + 8 + 8 + 4 + 6 = 62 → 填充到64
```

**高性能原语替换** (Figure 9):
- Gaussian → Quartic kernel (15/16·(1-x²)²)
- Sine → Triangle wave (|x mod 2 - 1|)
- 节省0.25ms/帧，无质量损失

### 核心创新4: 路径终止启发式

**面积扩散启发式** (Bekaert et al. 2003):
```
子路径 x_1···x_n 的面积扩散:
a(x_1···x_n) = (Σ_{i=2}^n √(||x_{i-1}-x_i||² / (p(ω_i|x_{i-1},ω)|cosθ_i|)))²

主顶点 x_1 从相机看的面积:
a_0 = ||x_0-x_1||² / (4π cosθ_1)

终止条件:
if a(x_1···x_n) > c·a_0:  # c=0.01
    终止路径，查询缓存
```

**物理直觉**:
- 路径足迹足够大 → 模糊缓存的小尺度误差
- 自动适应BRDF粗糙度和距离

**训练后缀终止** (Figure 5):
```
渲染路径: x_0 → x_1 → x_2 (终止)
                        ↓
训练后缀:        x_2 → y_3 → y_4 (终止)
                        ↑
                以x_2为"主顶点"重新计算a_0
```

### 核心创新5: 时间稳定性

**指数移动平均权重** (EMA):
```
训练权重: W_t (用于优化)
推理权重: W̄_t (用于渲染)

更新公式:
W̄_t = (1-α)/η_t · W_t + α·η_{t-1} · W̄_{t-1}
其中 η_t = 1 - α^t (偏差修正)

α = 0.99 (平滑强度)
```

**效果** (Figure 3):
- α=0.00: 高频闪烁
- α=0.90: 减少闪烁
- α=0.99: 时间稳定 + 快速适应

### 实现细节

**网络架构**:
- 7个全连接层
- 5个隐藏层 × 64神经元
- ReLU激活函数
- **无偏置向量** (简化 + 性能)
- 输出层: 64 → 3 (RGB)

**优化器**: Adam
- β₁=0.9, β₂=0.99
- 每帧4次梯度下降步骤
- 每步16384个训练样本

**损失函数** (相对L2损失):
```
L²(L_s, L̂_s) = ||L_s - L̂_s||² / (sg(||L̂_s||²) + ε)

sg(·): stop gradient (阻止梯度)
ε = 0.01
```
→ 对噪声目标的无偏梯度估计

**反照率因子分解** (Figure 8):
```
网络输出 × (α(x,ω) + β(x,ω))

优势:
- Lambertian材质 → 相当于辐照度因子分解
- 恢复纹理颜色
- 网络专注于互补细节(高光)
```

**摊销策略**:
- **屏幕空间瓦片**: 1个随机偏移 → 稀疏训练路径
- **共享路径前缀**: 训练路径复用渲染路径的前几个顶点
- **自适应瓦片大小**: 动态调整以匹配训练预算

## 技术局限

### 1. 长镜面链 (Figure 15)

**问题**: Bistro玻璃场景
- 启发式无法终止分支镜面传输
- 32 spp: MRSE 2.79 → 2.45 (仅12%改进)
- 时间: 192ms → 320ms (反而变慢)

**需改进**:
- 更好的路径终止准则
- 更精确的缓存(分辨锐利镜面细节)
- 与路径引导结合

### 2. 缓存伪影

**频率编码副作用**:
- 轴对齐的空间振荡
- 直接可视化时明显

**当前解决方案**:
- 启发式延迟查询 → 通过粗糙反射模糊
- 仅在非主顶点查询

**未来方向**:
- 替代编码方案
- 视觉导向的稳定化

### 3. 光照分辨率限制

- 16×32探针 (512个光照采样)
- 无法恢复超高频内容
- 极硬阴影/锐利焦散有残留

### 4. 单次弹射直接光照

- 仅建模直接光照
- 缺失间接光照、全局光照
- 背光场景比GT暗 (Figure 5 D)

### 5. 时间伪影

**已解决**: 高频闪烁 (通过EMA)

**未解决**: 低频闪烁
- 微妙的scintillation
- 需视觉导向稳定化

## 技术细节补充

### 面积扩散公式推导

**Bekaert et al. 2003**:
```
像素足迹 → 主顶点足迹 a_0
主顶点足迹 → 子路径足迹 a(x_1···x_n)

递推:
a_i+1 = a_i + (d_i / √(p(ω_i)|cosθ_i|))²

几何解释:
- d_i: 边长
- p(ω_i): PDF (重要性↑ → 足迹↓)
- cosθ_i: 前缩短
```

### Tensor Core利用

**NVIDIA Ampere架构**:
```
矩阵乘法单元: 16×16×16 (FP16)
每个warp: 32线程
每个线程块: 4个warp = 128线程

映射:
64×64权重 × 64×128激活
= 4×4 个 16×16块 × 4×8 个 16×16块
= 每warp处理 1×8 个16×16块
= 4个warp处理完整矩阵乘法
```

    float* input,      // [N, 64]
    float* output,     // [N, 3]
    float* weights[7], // 层权重
    int N              // 批量大小
) {

    int block_id = blockIdx.x;
    int warp_id = threadIdx.x / 32;
    int lane_id = threadIdx.x % 32;

    // 每个线程块处理128个样本
    int batch_offset = block_id * 128;

    // L层循环
    for (int layer = 0; layer < 7; ++layer) {
        // Warp加载权重块到寄存器
        float weight_block[16][64];
        load_weights(weight_block, weights[layer], warp_id);

        // 矩阵乘法 (Tensor Core)
        for (int col_block = 0; col_block < 8; ++col_block) {
            wmma::mma_sync(...);  // 16×16×16
        }

        // 激活函数 (ReLU)
        if (layer < 6) {
            relu(activations[warp_id*16:(warp_id+1)*16][:]);
        }
    }

    // 写回输出
