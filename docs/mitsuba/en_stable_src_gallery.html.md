# Gallery[¶](https://mitsuba.readthedocs.io/en/stable/src/gallery.html#gallery "Link to this heading")
On this page you will find different 3D scenes ready to be used with Mitsuba 3.
All scenes in this gallery marked with [🅱️](https://benedikt-bitterli.me/resources/) originate from [Benedikt Bitterli’s rendering resources](https://benedikt-bitterli.me/resources/). On the official webpage you can also download the same scenes for other renderers such as PRBT 4 and Tungsten.
Check the LICENSE.txt file in the scene folder to learn more about the restrictions of a specific scene. Although note that the majority allow commercial use, and many don’t even require attribution.
