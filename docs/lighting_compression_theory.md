# Compression Theory Notes (SH + Low-Rank + FiLM)

> Goal: Provide a clear, paper-ready explanation (non-MLP) of the compression method used in this project.

## 1) Core idea (one sentence)
We compress the large spatio‑temporal SH tensor by factorizing it into a small set of **spatial basis functions** and **time‑dependent mixing weights**, where the weights are generated by a light‑conditioned FiLM‑style linear modulation.

---

## 2) Problem setup
For each probe position `p` and time frame `t`, we have ground‑truth SH coefficients:

- `S(p,t) ∈ R^27` (3rd‑order SH, RGB packed)

This is a very large tensor over **space × time × SH**.

---

## 3) Low‑rank spatial basis (no MLP)
We represent the SH at any position and time using a low‑rank basis:

```
Ŝ(p,t) = Σ_{k=1..K} w_k(t) · B_k(p)
```

Where:
- `B_k(p)` are **spatial basis functions** (static over time)
- `w_k(t)` are **time‑varying mixing weights**

### What is B_k(p)?
`B_k(p)` is a **learnable spatial field** (not a neural network). Typical realizations:

**(A) Grid / voxel basis (most intuitive)**

```
B_k(p) = TrilinearInterp(G_k, p)
```

`G_k` is a learnable 3D grid. Gradients only touch the 8 voxel corners around `p`.

**(B) Low‑rank factorized basis (more compact)**

```
B_k(p) = U_k(x) · V_k(y) · W_k(z)
```

Each factor is learnable, giving a compact representation.

**(C) RBF / Gaussian basis (smooth, sparse)**

```
B_k(p) = Σ_j a_kj exp(-||p − c_j||^2 / σ_j^2)
```

The actual implementation in this project follows a structured low‑rank basis (not an MLP).

---

## 4) FiLM‑style time modulation (light‑conditioned)
To model **dynamic lighting**, we do **not** use a deep MLP. Instead, we map a low‑dimensional light/time descriptor `c(t)` to mixing weights using a simple linear modulation:

```
w(t) = A · c(t) + b
```

This is the FiLM idea in its simplest form: **condition → linear map → feature scaling**.

So the full model is:

```
Ŝ(p,t) = Σ_k (A·c(t)+b)_k · B_k(p)
```

Where:
- `c(t)` encodes light position, color, frame index, etc.
- `A,b` are learnable parameters

---

## 5) Training objective
We minimize reconstruction error against ground truth:

```
L = Σ_{p,t} || Ŝ(p,t) − S(p,t) ||^2
```

### Gradient flow (important for explaining “optimization”)
Because `Ŝ` is a **linear combination**, gradients are simple and stable:

```
∂L/∂B_k(p) = Σ_t w_k(t) · ∂L/∂Ŝ(p,t)
```

And for FiLM parameters:

```
∂L/∂A = Σ_t (∂L/∂w(t)) · c(t)^T
```

So:
- `B_k` is optimized by back‑propagating through interpolation (grid or factorized basis)
- `A,b` are optimized by linear regression‑like gradients

---

## 6) Why this is *not* an MLP
- No deep nonlinear stack
- No black‑box mapping from (p,t) to SH
- The model is **explicitly factorized and interpretable**
- Time variation is handled via **linear modulation**

This makes the representation:
- Compact
- Fast at inference
- Easier to analyze and control

---

## 7) Intuition for readers
You can explain it as:

> We first find a small set of “lighting templates” over space (the basis). Then each frame only stores how much of each template to use. Dynamic lighting is modeled by linearly modulating these template weights using the light’s state.

---

## 8) What the representation captures
- Low‑frequency diffuse illumination
- Smooth spatial variation
- Efficient dynamic changes via modulation

It does **not** explicitly capture:
- High‑frequency specular highlights
- Sharp shadows / visibility discontinuities

These are outside the low‑frequency SH assumption.

---

## 9) Summary (paper‑style)
We compress the spatio‑temporal SH tensor using a low‑rank spatial basis and a FiLM‑style time modulation. The method avoids deep MLPs, retains interpretability, and provides a compact, fast‑to‑evaluate representation of dynamic diffuse global illumination.
