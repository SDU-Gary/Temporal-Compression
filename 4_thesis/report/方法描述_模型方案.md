# 方法描述（论文版）

## 问题定义
目标是在固定场景内，对**多光源配置**下的探针球谐（SH）进行高效压缩与重建。  
给定探针位置 **p** 与光照集合 **L**（多盏灯的描述与掩码），模型预测该位置的 **SH 系数**：

\\[
\mathrm{SH}(p, L) \in \mathbb{R}^{27}.
\\]

本方法采用**高斯混合 + 低秩分解 + 光照集合编码**的统一框架，使模型能在较高压缩率下保持稳定的重建质量。

---

## 数据与光照描述
训练数据以 `parametric_tensor.npz` 组织：
- `tensor[P, M, 27]`：探针 SH 系数（P probes × M configs）
- `probe_positions[P, 3]`：探针位置
- `light_configs[M, N, 12]`：多光源描述（N 个光槽，每个 12 维）
- `light_mask[M, N]`：光源有效掩码

光照使用 **统一 12 维描述向量**（Light Descriptor），包含光源类型、RGB 强度、位置与方向等，保证模型与光照方案解耦。

## 模型结构（Gaussian‑Physics Unified Set）
整体结构为：**光照集合编码 → 高斯权重 → 低秩重建 → 可选 FiLM 调制**。

### 1. 光照集合编码（LightSetEncoder）
对光源集合 \\(L=\{l_i\}\\) 进行编码，得到全局光照嵌入 \\(z\\)：

\\[
z = \sum_{i=1}^{N} m_i \cdot \mathrm{Embed}(l_i)
\\]

其中 \\(m_i\\) 为 mask。为保证线性性，编码采用**强度解耦**设计：  
\\[
\mathrm{Embed}(l_i) = I_i \cdot \mathrm{MLP}(f_i)
\\]
即仅由强度线性缩放，其余特征经 MLP 变换后进行 sum‑pooling。

### 2. 高斯权重（空间混合）
在探针位置 \\(p\\) 上选择 Top‑K 个高斯核：

\\[
w_k(p) = \frac{\exp\left(-\frac12 \| (p-\mu_k) / \sigma_k \|^2 \right)}{\sum_j \exp(\cdot)}
\\]

其中 \\(\mu_k\\) 为中心，\\(\sigma_k\\) 为尺度（log‑scale 参数化）。

### 3. 低秩分解与 SH 重建
每个高斯核维护低秩基与系数：
- \\(U_k \in \mathbb{R}^{27 \times r}\\)
- \\(C_k \in \mathbb{R}^{r \times d}\\)

最终预测：

\\[
\hat{y}(p, L) = \sum_{k=1}^{K} w_k(p) \cdot U_k \, (C_k z).
\\]

### 4. L0 分支（物理约束）
为保证能量项非负，对 L0（三个通道）引入专门分支并使用 softplus：

\\[
\hat{y}_{L0} = \mathrm{softplus}(\sum_k w_k U_{k}^{(0)}(C_k^{(0)} z)).
\\]

### 5. FiLM 动态调制（可选）
若启用 FiLM，对基函数进行条件调制：

\\[
U_k(z) = U_k \odot (1+\gamma(z)) + \beta(z)
\\]

其中 \\(\gamma, \beta\\) 为由 \\(z\\) 产生的调制向量。

## 伪代码（前向推理）
```text
Input: probe position p, light descriptors L=[l_i], light mask m
Output: predicted SH coefficients y_hat

1: z ← LightSetEncoder(L, m)          # sum-pooled, intensity-decoupled embedding
2: (w, idx) ← GaussianWeights(p, K)   # Top-K Gaussian weights and indices
3: Select U_k, C_k, U_l0_k, C_l0_k for idx
4: t_k ← C_k · z                      # time/lighting weights
5: t_l0_k ← C_l0_k · z
6: if FiLM enabled:
7:     U_k ← U_k ⊙ (1+γ(z)) + β(z)
8:     U_l0_k ← U_l0_k ⊙ (1+γ(z)) + β(z)
9: sh_k ← U_k · t_k                   # SH contributions
10: y_hat ← Σ_k w_k * sh_k
11: l0_k ← U_l0_k · t_l0_k
12: l0 ← Σ_k w_k * l0_k
13: l0 ← softplus(l0)                 # enforce non-negative L0
14: replace L0 channels in y_hat with l0
return y_hat
```

## 伪代码（训练流程）
```text
Input: dataset D={(p, L, m, y)}, epochs T, batch size B
Output: trained model parameters θ

1: initialize model θ, optimizer
2: for epoch = 1..T:
3:     for each batch in D:
4:         (p, L, m, y) ← batch
5:         y_hat ← ModelForward(p, L, m)
6:         L_recon ← reconstruction_loss(y_hat, y)
7:         L_l1 ← coeff_l1(θ)                      # |coeffs|
8:         L_lin ← linearity_loss(p, L, m, y_hat)  # optional
9:         L_sp  ← spatial_loss(p, y_hat)          # optional
10:        L_total ← L_recon + λ_l1 L_l1 + λ_lin L_lin + λ_sp L_sp
11:        backprop(L_total); optimizer.step()
12:    evaluate on validation set (MAE/RMSE/Charbonnier)
13:    log metrics & (optional) visualize via Rerun
14: return θ
```

## 算法框图描述（文字版）
**输入层**：探针位置 p 与光照集合 L（含 mask）。  
**编码层**：对光照集合做强度解耦的 MLP 编码并 sum‑pool 得到 z。  
**空间层**：基于探针位置选取 Top‑K 高斯核并计算权重。  
**低秩层**：以 \\(U_k, C_k\\) 对 SH 进行低秩重建。  
**调制层（可选）**：FiLM 基于 z 动态调制 \\(U_k\\)。  
**输出层**：合并各高斯核输出并替换 L0（softplus）得到最终 SH。

## 损失函数
训练目标由重建误差与若干物理/正则项组成：

\\[
\mathcal{L} =
\mathcal{L}_{\text{recon}}
 + \lambda_{l1}\, \mathcal{L}_{\text{coeff\_l1}}
 + \lambda_{lin}\, \mathcal{L}_{\text{linearity}}
 + \lambda_{sp}\, \mathcal{L}_{\text{spatial}}.
\\]

- **重建误差**：MSE / L1 / Charbonnier  
- **coeff_l1**：对系数矩阵的 L1 正则，稳定低秩分解  
- **linearity**：基于光源叠加的物理线性约束  
- **spatial**：KNN‑TV 空间平滑（可选）

## 训练细节
- 采样方式：Grid / Adaptive 两种探针布局  
- 学习率调度：常用 cosine / fixed  
- 模型超参：`NUM_GAUSSIANS=30`, `RANK=8`, `TOP_K=3`  

训练中记录：
- 训练曲线（total / recon / coeff_l1 / linearity / spatial）
- 验证指标（MAE / RMSE / Charbonnier / superposition）
  
视觉评估采用 **HDR → Reinhard → sRGB** 流程，使定性比较更稳定。

## 方法优势总结
1. **统一光照描述**：适配多光源集合，避免手工设计光照参数分支。  
2. **高斯局部性 + 低秩分解**：兼顾空间表达能力与压缩率。  
3. **物理一致性约束**：线性叠加与 L0 非负保持物理合理性。  
4. **可解释的压缩效率**：参数量显著小于原始 SH 张量，具备部署优势。  

该方案在保持低频光照重建质量的同时实现了高压缩比，为后续实时渲染或轻量化存储提供了可行的基础框架。
