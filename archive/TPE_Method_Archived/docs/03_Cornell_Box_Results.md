## 失败原因分析

### 1. 扰动范数与误差无关

| 时刻 | 扰动范数 | TPE贡献率 |
|------|----------|-----------|
| 9:00 | **0.11m** (最小) | **103.8%** (最差) |
| 15:00 | 0.32m | 147.8% |
| 6:00 | **0.77m** (最大) | 66.3% (最好) |

**结论**: 扰动大小与TPE效果**负相关** —— 这违反直觉！

### 2. TPE贡献率>100%的含义

当TPE贡献率>100%时：
```
E_tpe > E_total

意味着: TPE假设引入的误差 > 不做任何假设的误差
```

**解释**: 模型在某些维度上"修正"了TPE假设的错误。

### 3. 物理根源：多次反弹光照

Cornell Box特点：
```
      顶部
   ┌────────┐
左墙│        │右墙
   │  物体  │
   │        │
   └────────┘
      底部
```

- 光线经过5-6次反弹才到达探针
- 每次反弹改变光的方向和颜色
- 太阳方向变化 → **全局光照重新计算**
- **无法局部化为空间平移**

## 核心教训

1. **TPE假设在Cornell Box场景不成立**
2. **复杂间接光照无法简化为空间扰动**
3. **Spline插值是该场景的最优方法**
