# House场景对比实验

**场景**: 室外开阔建筑
**初衷**: 验证"开阔场景适合TPE"的假设
**结果**: 发现惊人的悖论

---

## 核心数据对比

### Cornell Box vs House

| 指标 | Cornell Box | House | 比值 |
|------|-------------|-------|------|
| E_total | 0.3590 | **0.0019** | **189x** |
| E_tpe | 0.3048 | 0.0018 | 169x |
| TPE贡献率 | 84.9% | **96.5%** | 1.14x |
| 扰动范数 | 0.11-0.77m | **0.0002-0.001m** | **500x** |
| Spline MAE | 0.0312 | **0.0002** | 156x |

---

## 惊人的悖论

### House场景的矛盾

```
✗ TPE贡献率: 96.5% (比Cornell Box更差！)
✓ 绝对误差: 0.0019 (比Cornell Box小189倍！)

矛盾：表面上更失败，实际上几乎完美
```

### 每小时详细数据

| 时刻 | 扰动范数 | E_tpe | TPE贡献率 |
|------|----------|-------|-----------|
| 6:00 | 0.001m | 0.0029 | 103.3% |
| 9:00 | 0.0002m | 0.0015 | 108.7% |
| 15:00 | 0.0005m | 0.0013 | 86.0% |
| 18:00 | 0.0008m | 0.0016 | 86.3% |

**观察**：
- 扰动几乎为0（0.0002m = 0.2毫米！）
- TPE贡献率>100%（与Cornell Box相同）
- 但绝对误差可以忽略

---

## 解读悖论

### 正确理解TPE贡献率

```
TPE贡献率 = E_tpe / E_total

Cornell Box: 0.3048 / 0.3590 = 84.9%
House:       0.0018 / 0.0019 = 96.5%
```

**关键洞察**：
- 百分比高不代表失败
- 要看分子的绝对大小
- House的96.5%是"0.0018中的96.5%"，仍然很小

### 为什么House误差如此之小？

#### 原因1：光照本身极其平滑

```
Spline MAE = 0.0002

这意味着：
  相邻小时的SH系数几乎线性变化
  三次样条几乎完美拟合
```

#### 原因2：环境光主导

开阔室外场景：
- 大量散射光
- 直射光被稀释
- 太阳角度变化的影响被平均化

#### 原因3：几何遮挡简单

```
Cornell Box:        House:
┌────┐
│    │              🏠
│ 物 │                ← 简单遮挡
│ 体 │              开阔空间
└────┘
复杂反弹            直射为主
```

---

## 为什么TPE"失败"了？

### 扰动范数告诉我们真相

```
Cornell Box: 0.11-0.77m  → 需要大扰动，但仍有大误差
House:       0.0002-0.001m → 几乎不需要扰动

结论: House场景根本不需要TPE！
```

**解释**：
- 光照变化太平滑，0.2毫米的扰动就够了
- 这说明**时间变化本身就微小**
- TPE是"杀鸡用牛刀"

### TPE贡献率>100%的再解读

```
Hour 9: TPE贡献率 = 108.7%

意味着:
  E_tpe = 0.0015
  E_total = 0.0013
  E_tpe > E_total

模型在"修正"TPE假设的误差
```

但由于绝对值都很小（0.001级别），这个"修正"无关紧要。

## Baseline对比

### House场景

| 方法 | MAE | RMSE |
|------|-----|------|
| **Spline** | **0.0002** | 0.0002 |
| DirectMLP | 0.0003 | 0.0006 |
| TDML | 0.0158 | 0.0195 |

**发现**：
- Spline几乎完美（MAE=0.0002）
- DirectMLP也很好（MAE=0.0003，仅差50%）
- TDML严重过拟合（MAE=0.0158，差50倍）

### 为什么TDML在House场景崩溃？

训练loss=0但测试差：
```
训练: 6个小时，完全拟合
测试: 泛化失败

原因:
  - 30k参数 vs 6个训练点
  - Fourier特征学到噪声模式
  - 对平滑信号，高频特征是噪声
```

## 核心教训

### 教训1：不要被百分比迷惑

```
错误判断: House TPE贡献96.5% > Cornell Box 84.9% → House更差
正确判断: House E_total=0.0019 << Cornell Box E_total=0.3590 → House问题太简单
```

### 教训2：TPE需要"恰到好处"的复杂度

```
太简单（House）:
  Spline就够了

太复杂（Cornell Box）:
  TPE假设失效

中等复杂度（？）:
  TPE可能有用
```

### 教训3：场景特性决定方法选择

| 场景类型 | 光照特性 | 最佳方法 |
|---------|----------|----------|
| 封闭室内 | 多次反弹 | 完整存储或混合模型 |
| 开阔室外 | 平滑变化 | **Spline插值** |
| 中等复杂 | 单次反弹主导 | TPE或Grid? |

---

## 意外收获

### 发现：简单场景的价值

虽然House场景"太简单"导致TPE无用武之地，但这个结果本身很有价值：

1. **定义了下界**：低于某个复杂度，不需要复杂方法
2. **验证了Spline**：在理论最优场景（平滑信号）确实最优
3. **挑战了假设**："开阔场景适合TPE"不成立
