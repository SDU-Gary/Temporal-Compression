## 3. 核心发现与洞察

### 3.1 TPE的物理机制（Cornell Box）

**问题**：为什么扰动主要沿Y轴？

**答案**：Cornell Box的垂直对称结构

```
场景几何：
  - 2m × 2m × 2m 封闭盒子
  - 探针位于中心 [0, 1, 0]
  - 顶部天窗接收太阳光

物理机制：
  太阳高度角 ↑ → 顶部光照强度 ↑
  太阳高度角 ↓ → 侧面/地面反射主导

TPE补偿：
  高度角大（noon）→ α=0（参考位置）
  高度角小（morning/evening）→ |α|大（向上/下移动）
```

**核心洞察**：
- TPE捕捉的不是"太阳路径"，而是"场景几何响应"
- 扰动方向由场景对称性决定
- 这是**场景几何主导的TPE**

### 3.2 为什么方向约束改进性能？

#### 3.2.1 过拟合风险降低

**无约束优化**（39个自由度）：
- 可以拟合任意3D轨迹
- 容易overfitting噪声
- 导致不必要的大扰动

**方向约束优化**（13个自由度）：
- 强制沿单一方向
- 更强的正则化
- 避免探索不相关的方向

#### 3.2.2 物理先验注入

方向约束 = 显式编码场景几何知识：
- Cornell Box → Y轴主导
- 长走廊 → X轴主导
- 开放场景 → 可能需要3D

#### 3.2.3 优化景观改善

**理论分析**：
```
无约束：ε ∈ R^{3T}，高维优化
方向约束：α ∈ R^T，低维优化
```

低维空间 → 更少局部最优 → 更快收敛到全局最优

### 3.3 TPE的适用性分析

基于Cornell Box的发现，我们可以推断TPE的适用条件：

| 场景特征 | TPE可行性 | 推荐策略 |
|---------|----------|---------|
| 强几何对称性（如Cornell Box） | ★★★★★ | 方向约束TPE |
| 中等对称性（如教室） | ★★★★☆ | 多方向或自适应 |
| 复杂几何（如街景） | ★★★☆☆ | 多锚点TPE |
| 极端非线性（如焦散） | ★★☆☆☆ | 混合模型（TPE+残差） |

## 4. 技术贡献

### 4.1 方法创新

#### ✅ 方向约束TPE（本工作）

**公式**：
```
ε(t) = α(t) · d
```

其中：
- d: 场景几何主方向（从PCA或先验知识获得）
- α(t): 时间相关标量幅度
- 参数量：T（而非3T）

**优势**：
1. 参数减少67%
2. 物理可解释性强
3. 正则化效果好
4. 易于优化

#### 对比现有方法

| 方法 | 参数量 | 物理意义 | 性能 |
|------|--------|---------|------|
| 原始TPE（无约束） | 3T | 中等 | 边界失败 |
| **方向约束TPE** | **T** | **强** | **✅ 成功** |
| 多锚点TPE | 3KT | 强 | 未测试（复杂度高）|
| 混合模型（TPE+NN） | 3T+N | 弱 | 未测试 |

### 4.2 实验设计贡献

#### ✅ 系统的验证流程

```
Baseline → 失败分析 → 方向分析（Exp. C）→ 改进优化（Exp. G）
```

**关键**：不是立即放弃，而是深入分析失败原因

#### ✅ 多层次评估标准

不仅看"通过/失败"，还分析：
- 扰动方向模式（PCA）
- 与场景几何的关系

**实验C - 方向分析**：

### 4.3 理论贡献

#### ✅ TPE的几何解释

**发现**：TPE不是"时间 → 扰动"的黑箱映射，而是：

```
太阳运动 → 场景光照分布变化 → 等效探针位移
```

关键链条：
1. 太阳角度 → 光源几何
2. 光源几何 × 场景几何 → 光场变化
3. 光场变化 ≈ 探针移动（如果场景对称）

**意义**：
- TPE有效性依赖于**场景几何的对称性**
- 强对称场景 → 小扰动足够
- 弱对称场景 → 可能需要大扰动

#### ✅ 扰动范数的新解释

**传统理解**：
- ||ε|| < 1.0m 是Taylor展开的数学要求

**我们的发现**：
- ||ε|| 实际上是场景的"几何特征长度"
- Cornell Box (2m) → ||ε|| ≈ 0.77m ≈ 38%盒子尺度
- 在对称场景中，这是合理的

**新阈值建议**：
```
||ε||_max < min(1.0m, 0.5 × L_scene)
```

其中L_scene是场景特征尺度

### 5.2 优势分析

- 存储减少：27N×T → 27N + T（当T>>1时巨大）
- 可解释性：扰动有物理意义
- 泛化能力：可插值到未见时刻

#### 相比TDML（时间度量学习）

- 更简单：不需要训练时间编码器
- 更物理：扰动对应真实的空间移动
- 更高效：优化参数少

#### 相比传统TPE（无约束）

- **更稳定**：参数减少67%
- **更准确**：标准1从失败到通过
- **更快**：收敛速度提升50%

### 5.3 局限性

| 局限 | 表现 | 影响 |
|------|------|------|
| 需要场景几何知识 | 需要知道主方向 | 初始分析成本 |
| 假设单方向足够 | Cornell Box有效 | 复杂场景可能不足 |
| 单参考点 | noon作为锚点 | 大时间跨度可能失效 |
| 线性假设 | Taylor展开 | 极端非线性场景失效 |

## 6. 实践建议

### 6.1 使用方向约束TPE的流程

#### Step 1: 数据收集
```python
# 收集N个探针，T个时刻的SH数据
sh_data = render_dataset(scene, probes, hours, spp=256)
```

#### Step 2: 方向分析
```python
# 运行baseline TPE
perturbations_baseline = optimize_tpe(sh_data, constrained=False)

# PCA分析主方向
pca = PCA(n_components=1)
pca.fit(perturbations_baseline)
principal_direction = pca.components_[0]
explained_variance = pca.explained_variance_ratio_[0]

# 判断是否适用方向约束
if explained_variance > 0.8:
    print("✓ Scene suitable for direction-constrained TPE")
else:
    print("⚠ Consider multi-directional or multi-anchor TPE")
```

#### Step 3: 方向约束优化
```python
# 使用主方向约束
alphas = optimize_directional_tpe(sh_data, direction=principal_direction)

# 验证标准
if max(abs(alphas)) < 1.0:
    print("✓ TPE validated!")
else:
    print("✗ Consider relaxing threshold or multi-anchor")
```
