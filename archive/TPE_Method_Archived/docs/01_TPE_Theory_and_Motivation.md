# TPE理论与动机

**Temporal Perturbation Embedding (TPE)**

---

## 1. 问题背景

### 1.1 多时刻光照存储的挑战

在动态场景的光照表示中，我们需要存储一天中不同时刻的光照信息：

```
传统方法：
时刻6点  → 27个SH系数
时刻7点  → 27个SH系数
...
时刻18点 → 27个SH系数

总存储量 = T × 27 = 13 × 27 = 351个浮点数
```

**问题**：
- 存储量随时间步数线性增长
- 对于密集采样（如每分钟）：1440个时刻 × 27 = 38,880个数
- 对于大规模场景（数千个探针）：存储量爆炸

### 1.2 现有方法的局限

| 方法 | 优点 | 缺点 |
|------|------|------|
| **完整存储** | 精确 | 存储量大 |
| **稀疏采样+插值** | 简单 | 需要密集训练数据 |
| **神经网络** | 紧凑 | 训练慢，泛化差 |

**核心矛盾**：如何在**压缩率**和**精度**之间取得平衡？

---

## 2. TPE核心思想

### 2.1 基本假设

**关键洞察**：时间变化的光照可以被建模为**空间上的扰动**

```
F(x, t) ≈ F_static(x + ε(t))
```

**用人话说**：
> "在位置x、时刻t看到的光照，等价于在另一个位置x+ε(t)、参考时刻看到的光照"

### 2.2 物理直觉

想象地面上的影子随太阳移动：

```
早上8点，杆子在位置A：
    ☀️ (东边)
     \
      \  |杆子
       \ |
    =====影子====

正午12点，杆子仍在位置A：
      ☀️ (正上方)
       |
       |杆子
       |
      影子(正下方)
```

**TPE的想法**：
- 不需要存储"早上8点"的完整光照数据
- 只需存储：**向西移动0.5米**这个扰动向量
- 在新位置查询参考时刻的静态光照场

### 2.3 数学表达

#### 完整框架

```python
# 1. 静态光照场（只存一次）
F_static(x) = GaussianMixture(x) → Latent → DecoderMLP(latent, x, sun_ref) → SH

# 2. 时间扰动（每个时刻存3个数）
ε(t) = [Δx(t), Δy(t), Δz(t)]  # 3维向量

# 3. 动态查询
F(x, t) ≈ F_static(x + ε(t))
```

#### 压缩效果

```
传统方法: T × 27 = 13 × 27 = 351个数

TPE方法:
  - 静态场: 1 × 27 = 27个SH系数
  - 扰动: T × 3 = 13 × 3 = 39个扰动向量
  - 总计: 27 + 39 = 66个数

压缩比: 351 / 66 ≈ 5.3x
```

## 3. 方向约束的TPE (Direction-Constrained TPE)

### 3.1 进一步简化

观察到太阳运动有**主方向**，可以进一步约束：

```
ε(t) = α(t) · d
```

其中：
- `d` 是固定的单位方向向量（3个数，全局共享）
- `α(t)` 是每个时刻的标量幅度（1个数）

#### 极致压缩

```
参数量:
  - 静态场: 27个SH系数
  - 方向d: 3个数（全局）
  - 幅度α: T × 1 = 13个数
  - 总计: 27 + 3 + 13 = 43个数

压缩比: 351 / 43 ≈ 8.2x
```

### 3.2 自由度对比

| 方法 | 自由度 | 表达能力 |
|------|--------|----------|
| 完整存储 | T × 27 | 完全自由 |
| 无约束TPE | T × 3 | 3D扰动 |
| 方向约束TPE | T × 1 | 1D扰动 |
| Spline插值 | 0（确定性） | C²平滑 |

## 4. TPE的理论优势

### 4.1 物理先验

TPE假设编码了物理直觉：
- 太阳位置变化 → 阴影移动
- 阴影移动 ≈ 空间平移
- 间接光照变化相对缓慢

### 4.2 数据效率

```
训练数据需求:
  传统神经网络: 需要T个完整样本
  TPE: 只需1个参考时刻 + T个扰动
```

### 4.3 泛化能力（理论上）

```
已训练: 6, 7, 8, ..., 18点
查询: 7.5点（未见过）

TPE方法:
  ε(7.5) ≈ 0.5 · ε(7) + 0.5 · ε(8)  # 插值扰动
  F(x, 7.5) ≈ F_static(x + ε(7.5))  # 查询静态场
```

---

## 5. 预期适用场景

### 5.1 理想场景

TPE应该在以下场景中表现良好：

1. **开阔室外场景**
   - 直射光主导
   - 遮挡简单
   - 阴影平移明显

2. **简单几何**
   - 少量几何体
   - 光线多次反弹少
   - 光照变化可局部化

3. **平滑时间变化**
   - 太阳角度缓慢变化
   - 无突变（如开关灯）
   - 连续动态

### 5.2 挑战场景

TPE可能失效的场景：

1. **复杂室内**
   - 多次间接光照
   - 全局光照变化
   - 空间扰动无法捕捉

2. **快速动态**
   - 光源突然变化
   - 几何遮挡突变
   - 非连续变化

## 6. 与现有方法的关系

### 6.1 vs 静态NeRF

```
静态NeRF: (x, y, z) → (RGB, σ)
动态NeRF: (x, y, z, t) → (RGB, σ)
TPE: (x + ε(t), sun_ref) → SH
```

**区别**：
- NeRF直接建模4D时空
- TPE将时间编码为3D空间扰动

### 6.2 vs D-NeRF

D-NeRF分解：
```
x' = x + Δ(x, t)  # 变形场
F(x, t) = F_canonical(x')
```

TPE分解：
```
x' = x + ε(t)  # 不依赖位置！
F(x, t) = F_static(x')
```

**关键差异**：TPE的扰动**与位置无关**，只依赖时间

### 6.3 vs HexPlane/K-Planes

HexPlane：
```
feature(x, y, z, t) = Grid_XY + Grid_YZ + Grid_ZX + Grid_XT + Grid_YT + Grid_ZT
```

TPE：
```
feature(x, t) = GaussianMixture(x + ε(t))  # 扰动后查询
```

**TPE更紧凑**：不需要6个时空平面的存储

## 7. 实现细节

### 7.1 静态场建模

使用Gaussian Mixture + MLP解码器：

```python
class StaticField:
    def __init__(self):
        self.gaussians = GaussianMixture(n=1, latent_dim=9)
        self.decoder = DecoderMLP(
            input_dim=15,  # 9 latent + 3 pos + 3 sun
            output_dim=27  # SH coefficients
        )

    def query(self, x, sun_dir):
        latent = self.gaussians(x)
        sh = self.decoder(latent, x, sun_dir)
        return sh
```

### 7.2 扰动优化

```python
# 目标：最小化重建误差
loss = ||F_static(x + ε(t)) - F_gt(x, t)||²

# 优化变量：
#   - ε(t) for t in [6, 7, ..., 18]
#   - 约束: ε(ref) = 0
```

### 7.3 方向确定策略

1. **PCA分析**（首选）：
   ```python
   # 对扰动向量做PCA
   pca = PCA(n_components=1)
   d = pca.fit_transform(perturbations)
   ```

2. **Y轴退化**（fallback）：
   ```python
   # 太阳主要在XZ平面移动，Y轴扰动为主
   d = [0, 1, 0]
   ```

## 8. 验证标准

为了验证TPE假设，我们设计了以下判断标准：

### 8.1 定量指标

1. **扰动范数约束**：
   ```
   ||ε(t)||_max < 1.0 米
   ```
   如果扰动过大，说明"空间平移"不合理

2. **重建误差分解**：
   ```
   E_total = E_generalization + E_tpe_assumption

   判断: E_tpe_assumption / E_total < 50%
   ```
   TPE假设误差应该小于总误差的一半

3. **时间平滑性**：
   ```
   avg||ε(t+1) - ε(t)|| < 0.5 米
   ```
   扰动应该随时间平滑变化

### 8.2 定性观察

- 扰动方向与太阳运动一致
- 扰动幅度随太阳角度变化单调
- 视觉上渲染质量可接受
